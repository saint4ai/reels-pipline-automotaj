# Проекты роликов

Сюда `bash scripts/new-video.sh <id> <reels|youtube> <запись.mp4>` кладёт проект: `BRIEF.md`, `CONCEPT.md`, `SCRIPT.md`,
`DIRECTION.md` (карта монтажа), `DECISIONS.md`, `transcript.json`, `assets/`, `renders/`. Код ролика — в `studio/src/videos/<id>/`,
запись — в `studio/public/projects/<id>/`. Записи и рендеры в git не попадают.
