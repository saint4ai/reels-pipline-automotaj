## Дизайн-система Codex — снята с кода, не с кадров (v3)

Разбор кадров дал раскладку, но не облик: v2 повторила зоны Codex и всё равно выглядела «криво».
Причина — токены. Ниже что именно отличалось и что перенесено (`frame.md` — полный список).

| Элемент | Codex (vibecoding, CSS) | v2 | v3 |
|---|---|---|---|
| Канвас | 3-стоп платина + 2 радиальных блика + сетка 96 @ .075 + свип | плоский градиент, сетка 64 @ .06 с перспективой | как Codex |
| Окно спикера | рамка 3px, тень 18px 18px 0, прямые углы | скругление 28, размытая тень | как Codex |
| Карточка | рамка 3px, тень 14px 14px 0, paper .86 | рамка 2px, скругление 16, тень 18px | как Codex |
| Надзаголовок | IBM Plex Mono 18 / .13em | Gilroy 700 20 | как Codex |
| Заголовок | 68–84 / .92 / −.055em | 76 / .95 / −.01em | 72 / .92 / −.055em |
| Акцент | чёрный текст на маркере | цветной текст с обводкой | маркер |
| Курсив | отдельные рукописные подписи с лаймовой чертой | только subline | `note` в трёх сценах |
| Субтитры | плашка .30 по содержимому, слова #d6d6d6, активное белое с подъёмом | плашка на всю полосу, серые #6e6e6e | как Codex, кегль 66 |
| Режимы | split / fullscreen / talking-head overlay | только split | + fullscreen (коннектор) |

Правило на будущее: прежде чем собирать «как у X», выписать токены из CSS X, а не из снимков.
