## Исходники для новых роликов

Транскрипт подкаста с пословными таймингами получен из субтитров YouTube:

```bash
yt-dlp --skip-download --write-auto-sub --sub-lang "ru-orig,ru" --sub-format json3 \
  -o "podcast.%(ext)s" "https://www.youtube.com/watch?v=DMcdly6qVd8"
```

Whisper локально **не запускать** — кладёт мак. Субтитры YouTube дают тот же результат
без нагрузки.
