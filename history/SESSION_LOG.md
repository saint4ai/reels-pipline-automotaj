# Как мы к этому пришли

Хронология работы над монтажом рилсов, 28–30 августа 2026. Написано для агента,
который продолжит работу с другой машины: здесь то, что не выводится из кода.

## Исходная задача

Автор (@saint4ai, onAI Academy) режет вертикальные рилсы из записей подкастов.
Материал — подкаст про ИИ, 75 минут, три участника: Ведущая (ведущая), Гость, Автор.

## Что перепробовали и чем кончилось

### Редакторы: четыре провала и два рабочих

Задача была найти связку «агент собирает монтаж программно → человек правит мышкой».

| Инструмент | Итог |
|---|---|
| **CapCut** | ❌ Сгенерированный проект не появился в списке черновиков. Формат закрытый, нужна регистрация во внутренней базе |
| **Shotcut (MLT XML)** | ❌ Открыл только видеонарезки: без шрифтов, без логотипа, без анимаций |
| **Remotion Studio** | ❌ Это не визуальный редактор. По объектам нельзя кликнуть — только правка кода и панель props |
| **DaVinci Resolve** | ❌ Отклонён самим Автором: «мы его не используем» |
| **FableCut** | ✅ Работает. Браузерный редактор, весь проект в одном `project.json`, есть MCP и REST |
| **Palmier Pro** | ✅ Работает. Нативный macOS, 50 инструментов MCP. Но своя расшифровка русский не знает |
| **HyperFrames** | ✅✅ **Взят как основной.** HTML+CSS+GSAP → MP4 одним проходом |

Проверка редакторов шла через веер агентов со скептиками — вывод в `reference/`.

### Форматы монтажа: три поколения

**Первое — субтитры поверх лица.** Пословные субтитры внизу, заголовок сверху.
Автор: «прикольно, но всего лишь одна анимация».

**Второе — вставки поверх видео.** React-компоненты с прозрачным фоном: плашки по шагам,
бейдж с цифрой, схема-цепочка в финале. Автор: «охуенно», но потом — «плашки в плашки
выкатываются», то есть каждая новая стирает предыдущую, структура не возникает.

**Третье — разделённый экран (текущее).** Сверху доска с накапливающимися строками,
посередине субтитры, снизу голова в скруглённом окне. Это то, на чём остановились.

### Ключевой разворот: «одна анимация плавно перетекает в другую»

Автор дал референс — YouTube `KV9c3qx8JSU`, отрезок 12:39–13:15, и попросил
разобрать по кадрам. Разобрали 30 кадров. Что оттуда вынесли:

1. **Карточка-контейнер живёт постоянно**, не исчезая. Меняется только начинка.
2. **Строки накапливаются**, а не заменяют друг друга. Прежние приглушаются, активная горит.
3. **Постоянный якорь** — линия внизу карточки, которая не меняется никогда.
4. **Субтитр одной короткой строкой** между карточкой и головой.
5. **Полная статика**: ни одного зума.
6. **На кульминации меняется цвет самой карточки** — она заливается акцентом.

Это перестроило подход: вместо семи отдельных карточек — одна доска на весь ролик.

## Что Автор забраковал (важно не повторять)

- **Зумы.** «Зумы вообще не надо использовать, они у тебя плохо получаются».
- **Меняющиеся заголовки.** «Субтитры читать и твои заголовки одновременно человек не сможет».
  Решение: один постоянный заголовок либо доска, но не мигающие подписи.
- **Три перекодирования подряд.** Битрейт падал с 7.7 до 4.7 Мбит/с. «Качество — пиздец».
  Решение: один проход ffmpeg через `filter_complex`.
- **«Моя платформа была дырявой»** — формулировка звучит смешно, не так.
- **Текст вместо смысла.** Последняя претензия: «креативности ноль, ты просто тупо
  анимировал текст. Никакой смысловой анимации нет». Это открытая задача — см. `history/OPEN.md`.

## Нарезка подкаста

75-минутный подкаст разобран по транскрипту с пословными таймингами. Работали агенты:
три разбирали части, потом каждый фрагмент оценивался по пяти критериям
(крючок / самодостаточность / конкретность / эмоция / законченность, до 20 баллов каждый).

Итог: 33 фрагмента. 17 с Автором (нарезаны вертикалью), 16 с остальными (16:9).
Имя файла = балл + заголовок. Полная опись с разборами — `reference/clips-index.md`.

⚠️ **Фрагмент с наибольшим баллом (86) — ловушка.** «В Казахтелеком не берут тех кто не
вайбкодит» — это пересказ слов министра от первого лица, а не заявление Автора.
Проверено по транскрипту. Без титра «цитата министра» клип читается как его личное
объявление о найме.

## Технические грабли, стоившие времени

Полный список — `knowledge/05_pitfalls.md`. Самые дорогие:

1. **Прозрачность из Remotion.** ProRes 4444 и webm альфу НЕ сохраняют. Работает только
   `--sequence --image-format=png`. Потеряли два подхода, пока выяснили.
2. **`fitText.ts` знает только заглавные буквы.** Для текста в обычном регистре завышает
   ширину и ужимает кегль до нечитаемого. Лечится `fitText` из `@remotion/layout-utils`.
3. **Шрифты держались на системной установке.** `loadFont` вызывался только в
   незарегистрированной композиции — на другой машине всё рендерилось системным sans-serif.
4. **HyperFrames сам управляет видимостью клипов.** Анимировать `visibility`/`opacity`
   на элементе с `class="clip"` нельзя — линтер отбраковывает. Оборачивать во внутренний div.
5. **Разбивка заголовка на буквы рвёт слова** посреди строки: «ПРИШЁЛ В К / ОД».
   Лечится обёрткой слов в неразрывные блоки.
6. **Оригинал подкаста на 5 ГБ перестал читаться** — песочница блокирует доступ именно
   к нему, при этом папка и нарезки открываются. Резали из готовых нарезок.
