# Безопасность

Репозиторий публичный. **Учётных данных в нём нет и никогда не было**: история состоит
из одного коммита, дерево проверено поиском по шаблонам ключей — совпадений ноль.
Не верьте на слово, проверьте сами, это одна команда:

```bash
git log --oneline | wc -l          # 1 — вся история
git ls-files -z | xargs -0 grep -nIE \
  'sk-[A-Za-z0-9_-]{16,}|ghp_[A-Za-z0-9]{20,}|EAA[A-Za-z0-9]{40,}|xox[baprs]-|AKIA[0-9A-Z]{16}|-----BEGIN [A-Z ]*PRIVATE KEY|Bearer [A-Za-z0-9._-]{24,}'
```

Пустой вывод второй команды означает, что ключей в дереве нет.

Здесь также нет: медиа клиентов, исходных подкастов, финальных рендеров, адресов и доступов
к серверам. Только код, база знаний и конфигурация.

## Правила для тех, кто берёт пайплайн себе

- Не коммитить ключи, токены, cookies, приватные ключи, медиа клиентов и учётные данные —
  ни в публичный репозиторий, ни в приватный. Обычный коммит поверх не стирает историю Git.
- Секреты держать в переменных окружения или менеджере секретов ОС.
- Ключи сторонних сервисов (21st.dev, HeyGen, провайдеры моделей) задаются переменными
  окружения на вашей машине.
- Переписывание опубликованной истории и force-push — отдельное решение, согласованное
  со всеми, у кого есть клон.

Если ключ всё же утёк: сначала отозвать, потом выпустить замену, потом обновить
конфигурацию — и только затем думать о чистке истории. В таком порядке.
