# Безопасность

Репозиторий публичный. **Учётных данных в нём нет** — ни в текущем дереве, ни в одной
ревизии истории. Не верьте на слово, проверьте сами, это одна команда:

```bash
bash scripts/check-secrets.sh              # текущее дерево
bash scripts/check-secrets.sh --history    # все ревизии
```

`секретов не найдено` и код возврата 0 означают, что чисто. Скрипт ищет ключи Anthropic,
OpenAI, GitHub, GitLab, Meta, Slack, AWS, Google, HuggingFace, Perplexity, Firecrawl,
приватные ключи PEM, JWT и строки подключения к базам, а также файлы, которых в
репозитории быть не должно: `.env`, `*.pem`, `id_rsa`, `cookies.json`, `*.session`.

Здесь также нет: медиа клиентов, исходных подкастов, финальных рендеров, адресов и доступов
к серверам. Только код, база знаний и конфигурация.

## Правила для тех, кто берёт пайплайн себе

- Не коммитить ключи, токены, cookies, приватные ключи, медиа клиентов и учётные данные —
  ни в публичный репозиторий, ни в приватный. Обычный коммит поверх не стирает историю Git.
- Секреты держать в переменных окружения или менеджере секретов ОС.
- Ключи сторонних сервисов (21st.dev, HeyGen, провайдеры моделей) задаются переменными
  окружения на вашей машине.
- Переписывание опубликованной истории и force-push — отдельное решение, согласованное
  со всеми, у кого есть клон.

## Сторож стоит на трёх входах

1. **Перед коммитом** — хук, ставится один раз: `bash scripts/hooks/install.sh`.
   Коммит с ключом просто не создастся.
2. **На каждом пуше и pull request** — GitHub Actions, `.github/workflows/secret-scan.yml`.
   Проверяет и дерево, и всю историю тем же скриптом.
3. **Push protection GitHub** — включается в настройках: Settings → Code security →
   Secret scanning. Для публичных репозиториев бесплатно, отбивает пуш с ключом
   на стороне GitHub, до попадания в историю.

Ложное срабатывание снимается комментарием `allow-secret` в конце строки.

Если ключ всё же утёк: сначала отозвать, потом выпустить замену, потом обновить
конфигурацию — и только затем думать о чистке истории. В таком порядке: обычный коммит
поверх не стирает историю Git, а клон или форк мог быть сделан в любой момент.
