# Разбор монтажа Apple (isla.creator) — стилистика для нового бренд-кода

Источник: `reference/apple-style/ref.mp4` — 720×1280, 21.64 с, 646 кадров (29.9 к/с), звук aac 44.1 kHz.
Кадры: `reference/apple-style/frames/` (5 к/с, 108 кадров), листы `sheet-1…6.jpg`.

## Структура: пять блоков, всё построено на трёх шагах

| Блок | Окно | Что в кадре |
|---|---|---|
| Хук | 0.0–3.4 | Скруглённый квадрат с логотипом Apple, заголовок «Timeless Design», коралловая пилюля «монтаж Apple», подзаголовок «повтори в 3 шага!» |
| Переход | 3.4–4.4 | Коралловая волна поднимается снизу, затем «капля» проходит по кадру и смывает содержимое |
| Шаг 1 | 4.4–8.6 | «Премиальный дизайн»: пилюля «шрифт Apple», строка `SF Pro Light` + `SF Pro Bold`, карточка Apple-Style Palette с девятью плашками и хексами |
| Шаг 2 | 8.6–14.0 | «Фирменные анимации»: скруглённые карточки перетекают друг в друга — зелёное кольцо → виджет с орбитой → карточка follow → «ЛИЧНЫЙ БРЕНД 2026» |
| Шаг 3 | 14.0–17.6 | «Bounce animation»: пилюля «bounce it!», кнопка Apple Pay, Face ID, элементы прыгают с перелётом |
| Список | 17.6–19.4 | Заголовок «что нужно?» с синим выделением текста и круглыми ручками, ниже три пункта списка |
| CTA | 19.4–21.6 | Чёрная пилюля с синей папкой «Apple System» → кнопка «забрать все!», надпись «ПИШИ "+"» |

## Двенадцать приёмов, которые несут стиль

1. **Коралловая жидкая волна** снизу. Органическая клякса, поднимается, колышется, иногда заливает кадр целиком. Это одновременно фон, переход и подпись автора.
2. **Клякса-переход.** Между блоками по кадру проходит размытая капля и смывает содержимое. Не вайп и не затемнение, именно жидкая форма.
3. **Печать по словам.** Заголовок набирается словами: следующее слово сначала серое, потом чернеет. Ни одного появления целой строки сразу.
4. **Коралловые пилюли-метки** с белым жирным текстом. Всегда короткие, всегда сбоку или под заголовком, никогда не в центре.
5. **Скруглённые квадраты** (squircle) как единственная форма контейнера. Ни прямых углов, ни кругов.
6. **Перетекание карточек.** Одна карточка превращается в другую через масштаб и размытие: кольцо → виджет → профиль → цифра года.
7. **Bounce с перелётом.** Элементы приезжают с упругим промахом мимо конечной точки. Отсюда и название третьего шага.
8. **Мягкие цветные свечения** за карточками: зелёное, синее, сиреневое. Не тени, а расфокусированный цвет.
9. **Список по пунктам** с точками-буллетами, строки приходят по одной.
10. **Выделение текста как в iOS** — синяя подсветка с двумя круглыми ручками по углам. Приём-цитата из интерфейса.
11. **Ник автора в пилюле** сверху весь ролик: аватар плюс имя, светло-серая плашка.
12. **Ноль видео спикера.** Ролик целиком графический, лица нет ни секунды. Держит внимание темпом смены карточек: событие каждые 0.3–0.6 с.
