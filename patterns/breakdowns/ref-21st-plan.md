# План монтажа: рилс «Ты переплачиваешь за High» — стиль «лаборатория»

Проект: `videos/reels-2-effort-lab`. Длина 23.0 с, 1080×1920, 30 fps.
Референс структуры — `ref-21st-breakdown.md`. Стилистика — скиллы Эли, не наша платина.

## Почему это новый стиль, а не перекрашенный старый

| | Платина (всё, что делали до сих пор) | «Лаборатория» (этот ролик) |
|---|---|---|
| Холст | тёплый платиновый градиент + радиальные тинты по сценам | холодный off-white `#F4F5F3`, ровный, без тинтов и радиалов |
| Композиция | спикер снизу, канвас сверху, карточка внутри канваса | продуктовая поверхность во весь кадр, спикер только в хуке |
| Акцент | лайм `#B6FF00` + оранжевый + красный | один терракот `#C96442`, второго акцента нет |
| Кегли | 6 ролей (72/60/58/88/96/150) | ровно три: 150 / 64 / 40 |
| Жирности | 400/700/800/900 вперемешку | ровно две: 800 и 300 |
| Числа | Manrope ExtraBold | JetBrains Mono, `tabular-nums`, всегда |
| Тёмное | скин `ink` целиком тёмный | одно тёмное окно терминала на весь ролик, как единственное пятно |
| Объекты | counter/bars/note/stamp/chip из нашей библиотеки | блоки библиотеки `studio/src/kit`, а не наши руками |

## Токены

```
--paper   #F4F5F3   холст
--paper-2 #DEDFDB   вторая плоскость (шапка таблицы), ΔL* 7.8 к бумаге
--ink     #1A1C1B   весь основной текст и линии
--mute    #646A63   вторичный текст и данные (5.07:1)
--hair    #C9CBC6   только несущие линии сетки (1.50:1), текстом не использовать
--acc     #C96442   терракот: победитель, подчёркивания, дельты, CTA
--dark    #141615   фон единственного окна терминала
t-hero 150px / 700   один на кадр
t-mid   64px / 300   вводная строка, максимум одна строка
t-cap   40px / 300   подписи, оси, источник
Manrope 800/300 — текст. Лайм #B6FF00 в этом скине запрещён: на бумаге даёт 1.11:1. JetBrains Mono 500 — все числа, чипы, терминал.
```

## Субтитры

Две позиции, как в референсе. Пока в кадре спикер — пилюля сверху, кегль 40, скругление 6. Пока в кадре данные — крупная строка внизу, кегль 64, максимум две строки, ключевое слово терракотой. Подсветка слова управляется одним скаляром через `mk-callout-highlight`, поэтому синхронизируется по транскрипту, а не вручную.

## Правки после разведки контрастов (проверенные WCAG-отношения)

- `--mute #A3A8A2` из скиллов Эли на нашей бумаге даёт **2.21:1** и не годится ни для текста, ни для данных. Разведён на два токена: `--mute #646A63` (5.07:1) для текста и данных, `--hair #C9CBC6` (1.50:1) только для несущих линий сетки.
- `--paper-2 #EAEBE9` невидим: ΔL* 3.5, контраст к бумаге 1.09:1. Заменён на `#DEDFDB` (ΔL* 7.8).
- Лайм `#B6FF00` на бумаге — **1.11:1**, оранжевый `#FC5C02` — **2.88:1**. Оба ниже порога 3.0, поэтому единственный акцент терракот `#C96442` (3.57:1 на бумаге, 4.66:1 на тёмном).
- Сцена 4 переделана: `mk-clone-wall-transition` убран, он нарушает правило 7 разбора «ни одного перехода». Вместо него жёсткая склейка.
- Глубина в этом стиле берётся не из тени, а из перепада светлоты: бумага L* 96.4 против тёмного L* 7.0, контраст 16.62:1. Тени, рамки 3 px и скругления убраны полностью, единственное скругление 6 px на пилюле субтитров.
- Full-bleed относится к геометрии, не к содержимому: плеер Instagram режет 98 px с каждой стороны, поэтому поверхность выходит за края, а текст и числа остаются внутри безопасного бокса.

## Правка по итогам аудита контрастов (пересчёт своим скриптом WCAG)

- `#C9CBC6` на бумаге даёт **1.50:1**, а не 1.32:1 (ошибка на 13 %). ΔL* = 15.01. Значение 1.32:1 принадлежит
  другому цвету, `#D6D6D6`. Для несущих линий сетки годится всё равно: они не несут смысла, порог к ним не применяется.
- Пороги WCAG в этом файле не перепутаны, но записать их надо явно: **3:1** по SC 1.4.11 для графики, нужной
  для понимания (линии графика, точки, оси); **4.5:1** по SC 1.4.3 для обычного текста; **3:1** для текста
  от 24 px или от 18.5 px полужирного. Наш hero 150 px и mid 64 px попадают в крупный текст, то есть их порог 3:1.
