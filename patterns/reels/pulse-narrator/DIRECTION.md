## Что собрано

10-секундный пример на прежнем голосе пользователя, не новый полный Reel. Готовые крупные Fluent Emoji + Phosphor, существующий puppet rig v2, оранжевый badge, переход объекта в объект и в схему. Голова сохраняется все 300 кадров, перемещается по освобождённому коридору. Субтитры 40 px, серая подложка по строке и плавное подчёркивание слова. Готовые изображения не выдаются за оригинальные Apple-ассеты.

Первоначально автоматическая группировка отделила отрицание «не» от «помогут тебе». Добавлена опциональная смысловая группировка `captions.breakAfterWordIndices`. Проверено: 72 случая старого режима побайтово совпадают по структуре с прежним сборщиком; 6 неверных входов отвергаются. Девять новых групп сохраняют все 23 слова, отрицание не потеряно. Для старых проектов режим не меняется.

Убрана слишком большая декоративная эллиптическая поверхность: на снимках появлялся белый прямой обрыв фона. Вместо неё — полноэкранный мягкий градиент. Убраны конфликтующие по времени tweens secondary motion. Ошибочное motion-ожидание появления foundation на 8.6 s приведено к запланированному появлению 8.7–9.22 s; assertion проверяет 9.3 s, а не обходится.

## Результаты

- Финал: `renders/04-pulse.mp4`, SHA-256 `6aa04b44dd68ecd8e35576bc1bdc0743914af7b78d3c899ed11c8ba83a405ec6`, 4 447 277 bytes.
- H.264, 1080×1920, 30 fps, 300 кадров, 10.000 s; AAC 48 kHz stereo.
- Штатный экспорт CRF16/high, один worker/до четырёх CPU: 37 s на текущей машине. Это время рендера, не всей разработки и не стоимость токенов.
- Геометрия 300/300: 0 выходов главных групп, пересечений между ними, пропавших ресурсов/головы. Все видимые слова помещаются в карточки. Повторный seek: одинаковые геометрия и пиксели.
- Все 300 состояний jaw совпадают с реальной cached voice envelope. Отдельная проверка alpha-контура исходного лица: максимальный радиус 117.461 px при 120 px внутреннего радиуса круга; обрезанных кадров нет. Прозрачные углы PNG не считаются лицом.
- Созданы и просмотрены 3 листа всех 300 областей рта из фактического MP4; проверены чёрная полость и возвращение исходника в паузе. Это кукольное движение по амплитуде, не естественная артикуляция по фонемам. На непрерывной громкой речи рот долго остаётся широко открытым — ограничение текущей RMS-модели, а не доказательство фонемной точности.
- Просмотрен плотный переход из финального MP4 (12 кадров 3.30–4.03 s), контактный лист и опорные кадры. Схема уступает коридор движению головы, затем восстанавливает размер.
- 10 звуковых событий, 7 исходных файлов нового пака, 0 старых/смешанных событий; правило ≤20% соблюдено. Аудиокэш/trim/source SHA в `media/mix-manifest.json`.
- Декодированный AAC: sample peak −2.06 dBFS, 0 отсчётов полного масштаба. FFmpeg ebur128: −18.1 LUFS, LRA 2.8 LU, true peak около −2.1 dBFS. Это тихий демонстрационный микс с запасом, не заявление о целевом −14 LUFS. Энергия сигнала не заменяет субъективное прослушивание; плеер запускается со звуком.

Сохранившиеся штатные предупреждения: повторное использование PNG books, прозрачный native-size контейнер rig за пределами круговой маски, низкий контраст субтитров на коротком fade. Контур самой головы проверен отдельно. Битрейт 3.6 Mbps ниже общего предупреждающего порога 6; качество CRF16/high не снижалось, искусственное раздувание файла не сделано. Это не сертификация всех будущих UI площадок: конкретный выпуск снова проверять с актуальным overlay.

## Воспроизведение и экономия

Навык: `skills/onai-pulse-narrator/SKILL.md`; общий вход `knowledge/montage-concepts.md`; звук `knowledge/audio-apple-pack.md`. Канонический путь одинаков для Claude Code и Codex через проектные ссылки. В глобальные инструкции Windows/WSL записано обязательное согласование стиля до нового монтажа.

Не генерировались повторно лицо, озвучка, готовые библиотечные PNG/SVG; не повторялась ASR. Огибающая рассчитана локально один раз (0.09 s), затем проверяется по хешу. Новые npm/render-библиотеки не ставились. Короткий цикл формирует все кадры jaw; языковой модели не нужно описывать каждый кадр. Генерация неизвестных декоративных объектов не является обязательным этапом PULSE.

Ничего не опубликовано, не загружено в OneDrive и не отправлено в GitHub. Единственное удаление по текущему запросу — 17 проверенных Downloads-звуков отправлены в Windows Recycle Bin, копии в проекте сохранены. Старые звуковые библиотеки не изменялись.
