# Apple Depth — проба стиля, 06.09.2026

## V4 — official / real assets

После ревью v3 введён обязательный semantic asset gate: объект должен буквально объяснять произнесённое, узнаваться без подписи и не заменять доступный логотип/интерфейс фантазийной генерацией. Две абстрактные 3D-иллюстрации v3 отклонены как AI-slop и удалены из активного проекта.

Новая проверка использует крупные реальные окна и фирменные файлы только на таймкодах, где они семантически нужны:

- 0–8,9 с: реальный интерфейс пользовательского проекта, без выдуманной продуктовой капсулы;
- 16,44 с: оригинальный PNG Vercel поверх реальной записи Vercel;
- 43,44 с: оригинальный PNG Hetzner и официальное пресс-фото серверной инфраструктуры; источник виден в кадре.

V4 — всё ещё style proof, а не публикационный мастер. Длительность расширена до 50,5 с только ради проверки Vercel и Hetzner на фактических таймкодах речи. Между тестовыми сценами полный монтаж ещё не собран. Сначала три лёгких snapshot-кадра, без тяжёлого MP4-рендера.

Проверка v4: сборка schema 7 успешна; HyperFrames lint — 0 ошибок, 0 предупреждений. Просмотрены кадры 3,2 / 16,8 / 43,8 с и автоматически добавленный финальный кадр 48,985 с. Критичные подписи ограничены x120–840; большие реальные окна могут доходить до x960 как некритичный bleed. Snapshot занял около 12 с при одном процессе, `taskset 0-3`, `nice 10`, `ionice idle`; после завершения дочерних Chrome-процессов не осталось. Полный MP4 не запускался.

Полный HyperFrames `check` для растянутого, но намеренно неполного style-proof был остановлен: две проверки оставались живыми дольше 30 с. Это не выдано за PASS. Процессы завершены, повторный параллельный запуск запрещён; для этой итерации достаточно lint + детерминированных snapshot-кадров. Полная проверка относится к заполненному публикационному таймлайну.

## V3 — отклонено пользователем

По прямому замечанию Александра v2 всё ещё выглядела недостаточно качественно. Были сгенерированы две прозрачные 3D-иллюстрации: «готовый цифровой продукт» и капсула публикации. Пользователь справедливо определил оба объекта как нерелевантные и странные; они не прошли semantic asset gate и не входят в v4.

Этот вариант сохранён только как запись отклонённого решения: не возвращать его в монтаж и не использовать его промпты как шаблон.

## Текущая редакция v2 — замечание о масштабе

Первая проба оценена Александром как «плюс-минус», но окна слишком маленькие и качество ещё не устраивает. Не считать v1 утверждённой стилистикой.

- Вместо трёх одновременно мелких карточек — один крупный объект шириной 720 px, меняющийся на слова «сайт» и «автоматизацию». Приложение увеличено с 360×125 до 720×245; сайт с 230×125 до 720×245. Убрана грубая 10 px экструзия, оставлен тонкий торец и мягкая статичная тень.
- Окно браузера выросло с 600×338 до 716×403 (720 px с рамкой), внутри горизонтальной safe-zone. Заголовок освобождает ему место. Мелкий UI всего сайта по-прежнему не учебная демонстрация клика; в полной версии ему нужна отдельная крупная сцена/контекстный close-up.
- Из `.prfpset` взят принцип появления за 0.7 с: короткий сдвиг + blur → резкость. В нашем варианте 56 px и CSS blur 12 px; это адаптация, не прямое воспроизведение Adobe-параметров. Основные субтитры не искажаются пресетом растяжения.
- Пак разобран в `reference/breakdowns/polyas-presets.md`. Premiere и AE установлены, но импорт паков/Adobe-рендер не запускался. Веб-сервис пока не создан: сначала визуальная библиотека и проверенный renderer, затем интерфейс заданий. Гибрид с AE — возможный следующий этап, не уже реализованная функция.
- В этой редакции сначала проверочные кадры; старый `renders/apple-depth-preview.mp4` — это v1, не выдавать его за новый рендер.
- V2: validate BLOCKING 0; targeted check (1 midpoint + 1.2/2.5/3.35/8.63с) — lint/runtime/layout/motion/contrast 0 ошибок, 0 предупреждений. Просмотрены три новых кадра в `renders/qa/v2-snapshots/contact-sheet.jpg`. Лист снят за ~8 с с `--describe false`, без рендера нового MP4. В последней сцене рамка и подписи не заходят в полосу субтитров.

Это не финальный Vercel-рилс. Изолированный proof на первых 8.9 с речи; исходный Claude-проект не перезаписывается. Конец на завершённой фразе «могли этим пользоваться».

## Основа

Пользователь уточнил именно `Downloads/ПАК APPLE/ПАК APPLE/Фоны`. Три выбранных файла уже есть в подготовленном паке Vercel; копии сверяются по SHA-256. Не заменять их синтетическими обоями Cupertino.

Графит + зернистая платина, реальные экраны, матовые объёмные плашки. Белая Manrope, лайм означает доступ/результат, оранжевый — передаваемое действие. Без HUD, CASE, таймеров, случайных 3D-талисманов и ложных интерфейсов.

## Три приёма в пробе

1. 0–3.7: «Собрал. А как показать?» на зернистом фоне. На произнесённые «сайт» и «автоматизацию» приезжают разные связанные объекты. Объём — 2.5D-перспектива и статическая тень, не WebGL.
2. 3.7–7.44: тёмная сетка, проект → интернет. Линия на «выгрузить», принимающий узел на «публичный». Оранжевый пакет показывает направление передачи, а не декоративный трафик.
3. 7.44–8.9: синий фон, реальный стоп-кадр записи Александра, смысловой ярлык «Поделиться ссылкой». Скриншот здесь иллюстрирует результат; мелкий UI в нём не предназначен для обучения кликам. Для полной версии держать этот результат дольше: здесь последняя сцена короткая из-за длины первой законченной фразы.

Фон не обязан меняться каждые 3 секунды. Здесь три поверхности намеренно соседствуют для сравнения; финальный ролик может использовать только две. Движущиеся «Засветы» и «Градиент» найдены, но не вставлены ради количества. Засветы резервируем для 1–2 смысловых переходов (4–8 кадров, opacity ≤ .7), статичный градиент — для плотного текста.

## Ограничения этой пробы

- Начало ASR 0–1.06 с неразборчиво: не выдумываем текст, в пробе там только заголовок. Остальные слова и аудио из подготовленного Vercel-проекта.
- Спикер сохранён снизу; это проба графического слоя, не утверждение неизменного split-layout на весь финальный ролик.
- Safe box критичного текста x120–840; субтитры y808–928, выше окна спикера y960. Проверить по кадрам лицо и платформенные маски. Субтитры основным стабильным шрифтом, без искусственного рукописного слова в каждой фразе.
- «Klementina» найдена отдельно на Desktop. Для этой пробы не нужна: сначала оцениваем фон и движение, не меняем одновременно всё.
- Ролик не доказывает рост удержания. Проверять на реальных публикациях, сравнивая удержание и понимание материала.

## Экономика

HyperFrames 0.8.20 + HTML/CSS/GSAP, штатный сборщик schema 7. Нет миграции на React, второго рендер-движка, сервиса с базой/очередями или фонового демона. Один browser worker, 4 CPU, nice 10, I/O idle; ограничение применить и к QA. Статичные текстуры декодируются один раз, одна дорожка спикера; большой исходник не перекодируется. Локальные ссылки на prepared media исключают дубликат; для переноса нужен исходный `reels-5-vercel/media` либо упаковка ассетов.

CRF16 — качественная, но технически lossy-доставка, не математический lossless. Сохранение исходников и точной геометрии не равно отсутствию кодековых потерь. Не поднимать resolution ради мнимого качества.

## Источники технических решений

- https://hyperframes.heygen.com/concepts/frame-adapters — детерминированный seek; актуальная онлайн-документация не означает совместимость новых API с pinned 0.8.20. В пробе только уже используемый GSAP.
- https://www.adobe.com/learn/after-effects/web/create-fluid-text-animations?learnIn=1 — easing и motion blur как инструменты типографики. Здесь easing есть, дорогой полноэкранный blur не добавлен.
- https://vercel.com/geist/brands — официальный brand kit, правила логотипа и требования к использованию. В v4 логотип появляется на 16,44 с, когда бренд назван в речи.
- https://www.hetzner.com/pressroom/ — официальный PNG Hetzner, серверное пресс-фото и условия использования. В v4 источник указан непосредственно в серверном кадре.
