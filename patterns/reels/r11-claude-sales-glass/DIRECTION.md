# Claude: пять подключений для продаж — режиссура

## Последнее уточнение автора — постоянный Screen Studio portrait

Дополнение: автор отклонил один и тот же фон на всём ролике. Чередуем четыре среды по смысловым главам: светлая платина, графит с мягким оранжевым светом, глубокий синий, тёплая платина. Переходы .55 с, без белых вспышек. В тёмных средах плотнее светлые стеклянные поверхности; заголовки остаются на читаемой светлой плашке, отдельные рукописные заметки светлеют. Использованы исходные текстуры из пользовательского ПАК APPLE, без новых платных генераций и дополнительных видеодекодеров.

Окно автора — скруглённый квадрат 236–336 px, постоянно видимый, с перемещениями .68 с power3.inOut. Графика остаётся главным слоем. Верхний левый и верхний правый углы используются только в сценах с перестроенным заголовком; иначе нижние углы. Полноэкранный портрет в этом выпуске отменён. Субтитры остаются 40 px.

Автор разрешил квадратное кадрирование портрета при сохранении всей головы. Кадр источника 1080×1920 отображается через стабильный квадрат x0/y240/1080×1080; исходный файл не обрезается и не перезаписывается. Все детекции головы проверяются против этого квадрата и проецируются в движущееся окно на каждом кадре таймлайна. Для записей экрана по-прежнему только contain, без кропа. Лицо, окно автора, подписи и объекты проверяются на пересечения. Ранее описанный большой портрет заменён этим решением.

Основная мысль — перейти от просьбы написать пост к работе с бизнес-инструментами. Сохраняем именно авторскую запись IMG_7594.MOV и её формулировки, не переписываем речь под новый сценарий. Присланный текст служит редакционной опорой, ASR — временной разметкой. Бренды: Claude, Pipeboard, TikTok, Meta, YouTube, GREEN-API, WhatsApp, Fireflies, Apollo; Битрикс24 сохраняется официальным русским названием.

13 сцен: хук / рекламные сообщения и CRM / опыт / пять подключений / настоящий футаж Pipeboard / диалог WhatsApp / анализ звонка / 3 из 40 / поиск Apollo / подключение Битрикс24 / сделки-задачи-воронка / возврат к автору / «ПРОДАЖИ». Интерес поддерживается движением связей и смысловых объектов, не шумовыми HUD и случайными 3D-предметами. Футаж без кадрирования; записанные автором зумы остаются. Конец записи с чёрным кадром не используется. URL из скриншота печатается на отдельной читаемой карточке.

Утверждённый Liquid Glass: платина, мягкая кромка, локальный свет; реальный автор крупно или в углу. Лицо постоянно видно; перемещения прописаны в schema 7. Субтитры Manrope 40 px, светло-серые, подложка по фактической строке + 20 px поля, тонкое подчёркивание каждого слова. Caveat — отдельная короткая ремарка. Оригинал 2160×3840/50 fps SDR остаётся в Downloads; delivery — существующий 1080×1920/30 fps high/CRF16, не математически lossless.

Показ коннекторов является монтажной демонстрацией: реальные подключения/кабинеты не создаются, реклама не запускается. Схемы контактов и общения иллюстративны, без вымышленных реальных результатов и персональных данных. Цифры «4 года», «3 из 40», «сотни тысяч» — из авторской речи, не новые доказанные кейсы монтажёра. MCP-адреса воспроизводятся как даны пользователем; авторизационный handshake не тестировался. Фраза про тариф и возможности сервисов сохраняется как часть записи; монтаж не подтверждает, что все внешние подписки входят в $20.

Локальная транскрипция: faster-whisper large-v3-turbo / CPU int8 / 4 потока, из кэша. Исправления брендов и ошибок ASR перечислены в transcript-corrections.json. Слитое ASR «продавшей» исправлено на «продаж и»; интервал двух слов первоначально приблизительный и требует выборочного контроля. Речь не синтезируется и не заменяется.

Проверки: все кадры DOM, исходные боксы лица каждые .25 с, два ручных уточнения по реальным кадрам (профиль в начале и ложная детекция 55.75), каждый underline, соответствие ширины подложки тексту, неизменный кегль, safe-зоны. Новый V4 tracked-face принимает только полный свежий отчёт с хешами входов; V24 использует настоящие состояния из moves, не выключается. Перед сдачей — фактические кадры MP4 и подтверждение IN_SYNC конкретного файла OneDrive.

Финальная сборка описана в QA.md. Подготовленный микс был тихим (−28.36LUFS); двухпроходный звуковой мастер доведён до измеренных −16.24LUFS в AAC, peak−1.35dBFS. Итог `ONai_Claude_5_connections_Final.mp4` содержит тот же видеопоток, без повторного сжатия картинки. Нормализация выполняется отдельно после mix-audio.py, чтобы будущие выпуски не наследовали тихий промежуточный звук.
