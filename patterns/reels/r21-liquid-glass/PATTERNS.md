# Ролик 21 «монтаж» — новые приёмы и грабли (19.09.2026)

Код приёмов — `labs/remotion-route/src/kit/liquid/` (переиспользуемое) и `src/reels/montage/` (сцены этого ролика).
Переносится метод, не набор сцен: следующий ролик придумывает свою карту (правило 18.09).

## Библиотека `src/kit/liquid`

| Модуль | Что делает |
|---|---|

| `LiquidPanel.tsx` | Liquid Glass с настоящим преломлением: копия фона шире панели на поле + `filter: blur → url(#линза) → saturate`; материалы clear / frosted / milk / solid, тон dark / light / mint / orange, хроматика, лунный контровой свет, бегущий блик; проверка `[fit]` содержимого |
| `maps.ts` | карта линзы: SDF скруглённого прямоугольника, профиль кромки (приём K1), кэш по размеру |
| `CapsuleLine.tsx` | строка с жидкой капсулой по реальной ширине слов: капля растекается, перетекает между словами (передний край первым), сплющивается в растяжке |
| `words.ts` | раскладка строки через canvas `measureText` |
| `useAssetReady.ts` | ожидание шрифтов для замеров (с защитой от гонки, см. ниже) |
| `stage.tsx` | пять стилистик: `NightStage` (прожекторы-конусы, пыль в лучах, пятна света, луна с кратерами и лунным лучом), `GlassSphere`, `DawnSky` (слои облаков, подъём над облаками со звёздами), `Reeded` (рифлёное стекло), `Platinum` |
| `Object25D.tsx` | сгенерированный PNG-предмет как 2,5D: пружинный вход, парение, блик и контровой свет по альфе картинки |
| `Glyph.tsx` + `scripts/glyph-paths.mjs` | текст контурами настоящего шрифта (fontkit, вариативный вес); отверстие буквы — окно для пролёта камеры |

## Переходы этого ролика (в `src/reels/montage/Reel.tsx`)

- **Световая шторка** — прожектор далеко над кадром ведёт луч, пройденный сектор — уже новая сцена.
- **Пролёт сквозь букву** — зум ×70 в лог-шкале вокруг отверстия нуля, новая сцена в `clip-path: path()` отверстия, пересчитанного под зум.
- **Влёт в открытую коробку** — зум в раскрытие, мятная вспышка, новая сцена из размытия с отъездом.
- **Капсула становится миром** — `inset(... round r)` от капсулы до кадра, светящийся обод по краю.
- **Растворение пузырями** — SVG `clipPath` из растущих кругов.
- Плюс из библиотеки: вспышка цвета, размытие через белый, рывок с направленным размытием (`feGaussianBlur stdDeviation="X 0"`), подъём в тёмное.

## Субтитры — стеклянная капсула под строкой

`src/reels/montage/Captions.tsx`: строка = фраза речи (конец предложения, запятая после 3+ слов, пауза > 0,45 с, ширина 940 px);
капсула перетекает по ширине от строки к строке; `backdrop-filter` (лежит поверх сцен, в масштабе 1 кадр-в-кадр);
мятное подчёркивание слова по его таймингу; мета-приём — субтитры растут по команде из чата (`grow`).

## Грабли, которые поймали

- `backdrop-filter: url()` в Chrome Remotion молча не работает (O-1) → копия фона.
- `feImage` с процентами в `<svg 0×0>` — пустая карта, сдвиг всей панели (O-22) → размер в пикселях.
- `<g>` внутри `<filter>` выключает всю цепочку фильтров (O-23) → `<Fragment>`.
- Сверка кадров только в масштабе 1 (O-24).
- **Гонка шрифтов:** `loadFont` добавляет FontFace в `document.fonts` только после загрузки; `document.fonts.load()` на ещё не
  добавленное семейство сразу отдаёт пустой список — строки мерились запасным шрифтом и слипались в отдельных кадрах
  («Монтируетвсё» на 6,33 с). Ждать `faces.length > 0 && document.fonts.check()`.
- Капсула на соседних словах наезжала на слово → слова раздвигаются на поля капсулы (`gap`).
- Капсулы были впритык — текст местами чуть вылезал (Александр, 20.09): поля 0,4 кегля по бокам, 0,12 сверху/снизу; субтитры — 48 px.
- Луна без кратеров и луча — «нарисованная»; кратер кругом со светлым кольцом выглядит пузырём. Кратер = тёмный серп у стенки со
  стороны света, светлый серп дальней стенки, вал с градиентом света, центральная горка у крупных.
- Служебная QA-схема интерфейса Instagram («QA ONLY») в кадр не идёт — кнопки рисуются знаками.
- В общем `Root.tsx` параллельно работают другие сессии → у ролика своя точка входа `src/index-montage.ts`.
