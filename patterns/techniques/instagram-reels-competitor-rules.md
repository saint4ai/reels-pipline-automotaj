# Instagram competitor rules

Source audit: `reference/research/instagram-competitors-2026-09-06/`

- Treat keyword comments as conversion, not guaranteed reach. Use only when a named asset closes the Reel's exact loop.
- Portfolio mix: 45–50% proof/demo/news reach, 25% lead magnet, 15–20% authority/case, 10% real discussion.
- Best ONai format: give an agent a real business task, show the trace or interface, reveal a failure/correction, and end on a measurable consequence.
- First 2 seconds: result, interface, test, or conflict. Avoid generic title cards.
- Default length 35–55 seconds; test 60–75 only when extra time adds proof.
- Visual change every 3–4 seconds only for proof, orientation, escalation, or payoff.
- Use real UI, logos, screenshots, screen recordings, outputs, and physical objects. Decorative AI imagery is not evidence.
- Ask for one action. Do not stack comment + follow + save + share.
- For lead magnets: name the asset, use one short keyword, pin the instruction, and verify delivery.
- Evaluate performance relative to each account median and follower count, not raw views alone.
