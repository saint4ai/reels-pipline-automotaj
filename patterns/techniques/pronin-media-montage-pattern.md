# Pronin-паттерн для ONai

Полный аудит: `reference/research/instagram-competitors-2026-09-06/pronin-media-montage-audit.md`.

- Вход: ≥50 000 просмотров; дополнительно считать кратность медиане аккаунта.
- Скоринг: вирусность 30, компетенция 30, схема 20, доказательства 10, конверсия 10.
- Формат: «Вайбкодер: проверь систему» — один проверяемый вопрос на выпуск.
- Сюжет: риск → причина → схема → проверка → решение → один CTA.
- Первые 3 с: угроза/выгода + узнаваемый объект + короткая фраза.
- Низ — реальная говорящая голова; верх — один крупный объект; текст на шве.
- Объект развивается каждые 1–3 с, канвас остаётся стабильным.
- Абстракция становится формой, кодом, документом, счётчиком, таблицей, стрелкой или реальным UI.
- Берём грамматику, не стикеры: реальные логотипы, экраны, код и строгие SVG. Декор без смысла запрещён.
- Красный = риск, лайм = исправление, оранжевый = действие, чёрный = структура.
- Интерфейс сверху крупный; мелкие окна запрещены.
- Длинный ролик — только главы с мини-пэйоффом; основа ONai — 35–55 с.
- CTA показывает конкретную статью, чек-лист или файл; одно действие.
