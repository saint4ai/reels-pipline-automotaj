# Dashi-паттерн для ONai

Полный аудит: `reference/research/instagram-competitors-2026-09-06/dashi-agent-montage-audit.md`.

- Формат: «Стек под задачу» — 3–5 инструментов, каждый проходит мини-тест ONai.
- Хук обещает изменение результата, а не просто список сервисов.
- Пункт: порядковая глава → логотип → настоящий UI/код → одна функция → результат.
- Длина 30–48 с; заметная смена раз в 1,8–2,5 с.
- После 1–3 вставок вернуть спикера минимум на одну фразу.
- Доказательство показывать крупно: верхняя половина или полноэкранный режим.
- Не копировать карточки и типографику Dashi; использовать платиновый ONai-код.
- Не повторять список без собственного теста, ограничения или сравнения.
- CTA — только после пользы, одно кодовое слово, конкретная статья/набор ссылок.
- Pronin отвечает за системность/риск; Dashi — за новизну/инструменты. В одном Reel механики не смешивать.
