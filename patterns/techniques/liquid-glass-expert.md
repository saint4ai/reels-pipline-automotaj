# Экспертный Liquid Glass — решение от 09.09.2026

## Последнее уточнение — крупные объекты, wide-v2

Основной читаемый паттерн для Claude Code и Codex: [montage-pattern-ru.md](../skills/onai-liquid-glass-expert/references/montage-pattern-ru.md). Александр попросил увеличить объекты и слишком маленький квадрат автора. Старт композиции: x108…972 / y269…1536 (864×1267), автор обычно 304 px, субтитры прежние 40 px. Ориентир полей снизу 20%, справа 10% проверяется по реальному футажу интерфейса, это не универсальная безопасная зона. Старые 720 px ширины и квадрат 236 px больше не стандарт для следующего ролика. Числовой профиль — `layout-wide-v2.json` рядом с паттерном.

Обновление правил не меняет ранее выданный MP4 и не является PASS новой компоновки: сначала UI-маски, текст/лицо/пересечения, согласование старого V29 с проверенной геометрией. Ниже сохранена история реализации, а не конкурирующие актуальные координаты.

## Актуальное дополнение — смена фонов и квадрат автора

Александр одобрил четыре варианта: светлая платина, графит с оранжевым светом, глубокий синий, тёплая платина. Один фон на весь ролик признан монотонным. Чередовать среды по смысловым главам, переход около .55 с без вспышек. На тёмном фоне заголовок на светлой плашке, стекло плотнее, самостоятельные рукописные заметки светлые; контраст проверять также во время перехода.

Портрет — постоянно видимый скруглённый квадрат как Screen Studio, плавно меняет положение, не занимает по умолчанию весь экран. Разрешено отрезать окружающий фон исходника, но вся голова с запасом должна оставаться видимой на протяжении записи. Для футажей сохраняется contain. Кегль основных субтитров не увеличивать.

Текущая реализация: `videos/reels-11-claude-sales-glass`, `PORTRAIT-PATTERN.md`, исходные текстуры из пользовательского ПАК APPLE. Проверены 2110 кадров DOM, 181 подчёркивание, 282 замера головы; два замера уточнены вручную. Это не утверждение о готовом MP4. V4/V24/V27 интегрированы в production-сборку; старое описание демо и его ограничений ниже относится к первоначальному этапу. Подробные актуальные решения — общий навык `skills/onai-liquid-glass-expert`, ссылка `references/backgrounds-and-portrait.md`.

Общий новый навык: `skills/onai-liquid-glass-expert/SKILL.md`, подключён через `.agents/skills` и `.claude/skills`. После одобрения направления Александр уточнил: фон по фактической ширине строки с небольшими полями, светлее/серее; каждое произносимое слово плавно подчёркивается; размер основного шрифта прежний; рукописный акцент заменён на Caveat с кириллицей; звуки назначаются анимационным событиям. Эти требования важнее описания исходной версии ниже. Версия 2 остаётся демо без новой речи, не готовым production-Reel.

Александр запросил новую премиальную систему: он в кадре, кодовый монтаж, платиновое стекло, световой проход слева направо, плавные переходы и гармоничные субтитры.

Прямое уточнение во время работы: **не увеличивать размер субтитров; предыдущий размер нравится**. В демонстрации оставлено 40 px, отменён пробный размер 52 px. В следующем production-проекте брать типографику ранее утверждённого ролика, не объявлять 40 px универсальной нормой.

Шаблон и материальные токены: `videos/liquid-glass-expert-v1/PRESET.md`. Исходники — `parts/glass.*`; единый timeline, карта преломления, световой проход, стеклянные поверхности. PNG базы данных получен imagegen и сохранён с alpha; это 2.5D, не отдельная 3D-модель.

Проверка раскладки: `layout.mjs` возвращает безопасную полосу либо необходимость сменить раскладку. Неизвестная позиция лица не считается безопасной. `face-qa.py` и `qa.cjs` демонстрируют проекцию детекций лица через анимированное окно и проверку всех кадров DOM.

Старые прямоугольные стили, общий рендер и основной валидатор не изменены. Новый материал разрешает округления и мягкие тени только внутри этого пресета. Старые V4/V24 требуют отдельной интеграции новых состояний перед production: prototype не снимает требований качества.

Поставка этой сессии — **демонстрация стиля**, с прежней съёмкой без исходной речи и с примерами надписей. Новый исходник Александр предоставит отдельно. Нельзя выдавать демо за готовый к публикации ролик.

Рендер: стандартный `scripts/render-safe.sh`, 1 worker, не более 4 CPU, idle I/O, CRF16, 1080×1920/30 fps. Не запускать параллельно другие тяжёлые рендеры. После экспорта смотреть actual-MP4, не только HTML.
