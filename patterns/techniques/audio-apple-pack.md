## Выбор по действию

| Роль | Основные ID | Как применять |
|---|---|---|
| Упругое появление | rubber, ui-sequence | Мягкая посадка emoji/карточки; один звук на группу |
| Перестроение/сборка | transform-a, transform-b | Синхронно главному превращению, не каждому свойству |
| Фокус/крупность | mechanical-zoom | Короткий акцент смены смыслового масштаба |
| Переключение/подтверждение | switch, ui-sequence | На смене состояния или завершении связи |
| Счётчик | counter | На показе действительно меняющегося значения |
| Ввод текста | typing | На реальном наборе строки; не на каждом субтитре |
| Выход/размытие | blur-out | Короткий уход объекта, хвост не перекрывает новую речь |
| Ошибка/встряска | shake | Только при соответствующем смысле; не постоянный шум |
| Переход | whoosh-air, whoosh-sharp, whoosh-big, whoosh-long-2/3/4 | Большой перенос композиции, разные варианты по масштабу |
| Световой акцент | flash | Редко и по смыслу; не требует яркой экранной вспышки |

`UI sounds.mp3` — 31.687-секундный сборник отдельных акцентов, а не один готовый эффект. `typing` тоже содержит отдельные нажатия; у части whoosh есть начальная тишина. Индекс `segments` построен по активности сигнала: это кандидатные окна, не гарантия художественной пригодности. Перед выбором прослушать окно и проверить его с голосом. Окна не растягивать произвольно; короткие fades предотвращают щелчки.

**Разные звуки под каждый ролик (20.09.2026).** Александр: «в последнее время используешь одни и те же звуки». Под новый ролик
нарезать новые варианты из оригиналов пака (`originals/`, индекс `index.json` с окнами активности) в `labs/remotion-route/public/sfx`:
резкие вуши, большой вуш, длинные вуши 3/4, дрожание, вторая трансформация, отдельные щелчки из `UI sounds.mp3`. Ролик 22 использует
13 новых нарезок и 97 звуковых событий.

Звук можно пересобрать без рендера картинки: дорожка собирается ffmpeg по списку событий и вклеивается в готовое видео.
Громкость эффектов не поднимать ради «вау» — вау делает картинка.

Главный источник — голос. Огибающая рта считается только из чистой речи, не из речи со звуковыми эффектами. Снижение SFX под речью и мастеринг проверяются после AAC; громкость подбирается относительно конкретного голоса. Начальные ориентиры: peak SFX примерно −20…−14 dBFS до суммирования, голос отдельно нормализован; окончательный ориентир мастера −14 LUFS / ≤−1 dBTP не заменяет прослушивание.

В `concept.events` сохранять `at`, `soundId`, `segment`, `gainDb`, `role`, `reason`. Выбор делается заранее по seed и остаётся одинаковым при seek/рендере. Соседние макрособытия по возможности не используют один и тот же файл; внутри осмысленного набора кликов повтор допустим. Параллакс и дыхание фона обычно без звука.

Старые `make-sfx.py`, синтезированный набор трёх первоначальных демо и остальные прежние звуки **сохранять, не удалять**. В новых роликах минимум 80% звуковых событий используют только новый пак; до 20% могут использовать старые звуки или смеси старого и нового. Смешанное событие целиком считается в эти 20%, даже если старый слой тихий. Лимит считается по числу звуковых акцентов, не по длине треков: `old_or_mixed_events <= floor(total_events * 0.20)`. Это максимум, а не обязанность добавлять старые звуки. Не перемонтировать утверждённые примеры задним числом.

В cue manifest сохранять `library` (`apple-pack`, `legacy` или `mixed`) и происхождение каждого слоя. Старый слой должен быть смысловым дополнением, не случайным шумом. Если в обеих библиотеках нет нужного смысла, назвать пробел и записать лицензию дополнительного источника. QA проверяет пропорцию до рендера.
