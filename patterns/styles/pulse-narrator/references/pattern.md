# PULSE: паспорт и воспроизведение

## Демо, не новый сценарий

Проект: `videos/concept-04-pulse`. 10 s, 1080×1920, 30 fps. Первые 9.12 s утверждённого ранее `reels-6-base-before-courses/media/voice.wav`, затем короткий тихий финал. Текст взят из готовой транскрипции, без новой ASR/генерации голоса. Демо не публиковать как новый полноценный Reel.

| Время | Смысл | Визуальное действие | Звуковая роль |
|---|---|---|---|
| 0–3.35 | Не тратить деньги на очередное обучение без понимания | Шапочка и улетающие деньги, большие библиотечные 3D emoji | focus, pop, departure |
| 3.36–5.25 | Сначала разобраться с основой | Книги заменяют шапочку; лампочка — понимание; автор переезжает вниз | transform, idea |
| 5.6–8.7 | Готовые правила, скиллы и файлы не заменяют базу | Три крупных SVG-узла; связи рисуются вслед за появлением; пустое основание | UI clicks, constraint |
| 8.7–10 | Сначала база, потом инструменты | На место пустого основания входит полка с книгами | settle/transform |

Это собственная сборка из одобренных механик PRISM/ORBIT/TRACE плюс библиотечных метафор и прежнего rig. Не заявлять, что это четвёртый отдельно разобранный референс Apple или точное воспроизведение чужого проекта.

## Геометрия и движение

Критическая зона демо wide-v3: x44…840, y269…1536. Заголовок x84/y298/w476/h226; основной модуль x92/y564/w736/h552. Главные иллюстрации 430–450 px, дополнительные 248–300 px. После уточнения пользователя субтитры x76/y1390/w732/h100, Manrope 28 px/400/1.4 по образцу подписи TRACE, горизонтально по центру; чистый фон без плашки. Фон заполняет все 1080×1920, хотя UI-зоны свободны от значимых элементов.

Исправление 8 s: «А база?» min-width 340 px вместо 242, content-driven ширина, padding 28 px, gap 24 px, несжимаемый значок 65 px. Новая проверка content-fit ловит возврат старой тесной ширины. Итог обновления: `renders/04-pulse-fit-v2.mp4`; исходный `04-pulse.mp4` оставлен историей, не текущим образцом. Общие финальные правила: `knowledge/montage-final-contract.md`.

Голова: круг 248 px, старт (580,288), итог (94,1124). Сначала модуль коротко уменьшается до .60, освобождая правый коридор; голова спускается, затем едет влево ниже схемы; модуль возвращается к полному размеру. Нельзя просто провести автора через занятые карточки. При новом содержимом выбрать другой свободный маршрут, не копировать .60 механически во все сцены.

Всё движение задаётся GSAP x/y/scale/rotation и временем композиции. Никаких random/Date.now/RAF в финальном кадре. Пружины: back.out(1.12…1.55), 0.45–0.82 s; переезд power2/3.inOut. Вторичное движение 10–25 px, 1.2–2.15 s; фон около 100–220 px за 10 s с мягким градиентом. Эти величины — паспорт демо, не универсальный ритм всех роликов.

## Утверждённая голова

PNG source 1024×1536, alpha bbox (133,142,895,1338). Внутри круга общий rig в масштабе .184, смещение (25,−9), поворот вокруг (537,1310) исходника. Уменьшение через отдельный статичный родитель, jaw/face не растягиваются независимо.

Порядок: чёрная полость → неподвижная часть лица → подвижная челюсть. На закрытом рте виден исходник целиком. Jaw идёт по normal (0.1467,0.9892), максимум 64 px исходного размера. Общий sway 2.1°sin(2πt/6)+.35°sin(4πt/6), bob 2 px. Оранжевая заливка #FFB35A/#FF8A21/#FC5C02, обводка 4 px чёрная. Все четыре слоя PNG локальны.

`assets/puppet/analyze-audio.cjs` считает и кэширует RMS чистого голоса, 30 fps, attack .035 s, release .075 s. В демо 300 чисел, 0.09 s локального анализа на этой машине. Это не оценка стоимости токенов всей задачи. Повторный запуск с тем же SHA-256 использует кэш. Один небольшой цикл пишет ключи челюсти на таймлайн; 300 кадров не надо описывать языковой модели вручную.

## Минимальные команды

Из корня монтажного репозитория, с уже установленными Node/Python/FFmpeg:

```sh
node videos/concept-04-pulse/assets/puppet/analyze-audio.cjs videos/concept-04-pulse/media/voice.wav videos/concept-04-pulse/media/voice-envelope.json
python3 reference/research/concept-trio-2026-09-12/tools/prepare-pulse-demo.py videos/concept-04-pulse
python3 reference/research/concept-trio-2026-09-12/tools/mix-apple-pack.py videos/concept-04-pulse reference/audio/onai-apple-pack
python3 scripts/pipe.py build videos/concept-04-pulse
bash scripts/render-safe.sh videos/concept-04-pulse renders/04-pulse.mp4
```

`prepare-pulse-demo.py` предназначен только для 23 слов этого демо. Для нового ролика нужен собственный транскрипт и монтажный план. `mix-apple-pack.py` — ограниченный микшер чисто нового пака: старые/смешанные слои не игнорирует, а отклоняет с пояснением. Для их применения заранее свести конкретные слои существующим production-микшером/FFmpeg, проверить тот же лимит 20% и сохранить provenance каждого слоя. Не удалять старые библиотеки.

QA-инструменты в той же `tools/`: `qa.cjs`, `contact.py`, `final-proof.py`. `qa.cjs` — проверка 300 состояний этого демо, не универсальная автоматическая экспертиза любых видео. Прямой `page.evaluate` не должен возвращать GSAP Timeline: thenable может подвесить paused timeline. Кадры рта проверять отдельно от прямоугольника всей головы.

## Вариативность без хаоса

Можно менять: 3D-метафоры по смыслу, направление свободного маршрута, один из светлых/тёмных материалов после согласования, форму стеклянной полки, темп stagger, звуковые варианты. Не менять случайно: лицо, тезис, причинность связей, отрицание в субтитрах, CTA, исходные логотипы. Seed сохраняется до рендера. Не ставить один и тот же старт с деньгами и шапочкой на все темы.
