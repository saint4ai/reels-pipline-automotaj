# 10 — ПОРТРЕТ-КВАДРАТ

**Статус:** сдан в ролике 11 «Claude: 5 подключений»
**Композиции:** `PORTRAIT-Reels`, `PORTRAIT-YouTube`
**Код:** `studio/src/styles/portrait.tsx`, переезд квадрата — `ROAM` в `studio/src/styles/speaker.tsx`
**Ролик-образец:** `patterns/reels/r11-claude-sales-glass/` (PORTRAIT-PATTERN, frames.jpg)

## Механика
- Квадрат спикера переезжает на каждой смене блока по свободному нижнему коридору (центр → право → лево; в YouTube — правая колонка вверх/вниз), 0,6 с.
- Сцены чередуются: тёмное стекло / светлое стекло; схемы собираются в стеклянных карточках.

## Когда брать
Продажа через схемы, много смен раскладки, длинный список подключений.

## Раскладка
`speaker: roam`; графика — зона формата, квадрат её не перекрывает.

## Что менять под каждый ролик
Порядок положений квадрата, какие блоки тёмные и светлые.

## Что владелец принимал и отклонял
- Принято: четыре разные среды по смысловым главам вместо одного фона на весь ролик; новые объекты появляются после того, как квадрат доехал, если их пути пересекаются.


## Как собрать ролик в этом стиле

Данные ролика — те же блоки (`hook`, `list`, `stat`, `logos`, `flow`, `cta`) в `studio/src/videos/<проект>/project.ts`.
В точке входа ролика вместо шаблона взять стиль:

```tsx
import {calcStyle} from '../../styles/engine';
import {reelOf} from '../../styles';
import {PORTRAIT} from '../../styles/portrait';
const Reel = reelOf(PORTRAIT);
// <Composition id="<проект>" component={Reel} defaultProps={{format: 'reels', project: PROJECT}} calculateMetadata={calcStyle} … />
```

Своя механика блока, которой нет в стиле, пишется рядом в `studio/src/videos/<проект>/` из блоков `studio/src/kit`.
