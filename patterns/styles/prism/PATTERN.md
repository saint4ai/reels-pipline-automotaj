# 5 — PRISM (пластичный интерфейс)

**Статус:** утверждён 12.09.2026; эталон исполнения — ролик 14 Codebase Memory v016
**Композиции:** `PRISM-Reels`, `PRISM-YouTube`
**Код:** `studio/src/styles/prism.tsx` (`Morph` — капсула → карточка, `Background` — платина с мягкими пятнами)
**Ролик-образец:** `patterns/reels/r14-codebase-prism/frames.jpg`

## Механика
- Один стеклянный объект сохраняет идентичность: компактная капсула пружиной (`springAt`, одно превышение и затухание) раскрывается в объясняющую карточку.
- Форма меняется первой, строки входят с запаздыванием 0,3 с; содержимое раскладывается сразу в конечном размере — ничего не переносится.
- Светлая платина, белое стекло 70 % с кантом, один проход света по карточке; мягкие цветные пятна фона меняются на каждом блоке.
- Список — строки со значком и галочкой справа; цифра — число + сравнение «без / с»; схема — узлы-капсулы с тонкими изогнутыми связями, последний узел оранжевый.

## Когда брать
Показ сервиса, настройки, «как это работает».

## Раскладка
Спикер — карточка по формату; субтитры светлой капсулой (`light`).

## Что менять под каждый ролик
Направление раскрытия, какой контрол превращается в какой интерфейс, порядок групп, звук по роли (стекло, пружина, щелчок).

## Что владелец принимал и отклонял
- Принято (v016): первый кадр — контраст пользы (подписка ×10), карта и кэширование — следом; на каждом стыке сразу виден смысловой объект.
- Отклонено: три несвязанные карточки вместо одного превращающегося объекта.


## Как собрать ролик в этом стиле

Данные ролика — те же блоки (`hook`, `list`, `stat`, `logos`, `flow`, `cta`) в `studio/src/videos/<проект>/project.ts`.
В точке входа ролика вместо шаблона взять стиль:

```tsx
import {calcStyle} from '../../styles/engine';
import {reelOf} from '../../styles';
import {PRISM} from '../../styles/prism';
const Reel = reelOf(PRISM);
// <Composition id="<проект>" component={Reel} defaultProps={{format: 'reels', project: PROJECT}} calculateMetadata={calcStyle} … />
```

Своя механика блока, которой нет в стиле, пишется рядом в `studio/src/videos/<проект>/` из блоков `studio/src/kit`.
