## Начало

Прочитать [паспорт и монтажные условия](references/pattern.md). Исполняемый шаблон находится в `videos/concept-01-prism` репозитория `reels-montage-pipeline`; не искать его в репозитории сайта. Все пути ниже относительны корню этого монтажного репозитория. Шаблон, звук, источники и проверки передаются вместе с репозиторием.

Новая сцена: скопировать структуру storyboard/parts в новый проект, заменить демонстрационные подписи и медиа. `index.html` собирается через `scripts/assemble.py`, не редактируется. Основной движок остаётся HTML/CSS/GSAP; React не требуется.

## Отличительный механизм

- Один объект сохраняет идентичность: компактный контрол → раскрытый интерфейс → итоговое состояние. Не заменять это тремя несвязанными карточками.
- Форма меняется первой; заголовок/строки входят с небольшим запаздыванием. При входе не светить скрытой обратной стороной.
- Светлая платина, стеклянный кант, один проход света. Линза/оптика только за буквами и лицом.
- Пружина — короткое превышение размера и один затухающий отклик. Не качать все элементы одинаково.
- Портрет в скруглённом окне; перемещение только по свободному коридору, не случайно сквозь схему.

## Звук и вариативность

Палитра PRISM: air / bloom / glass / drop / pluck / switch / resolve / spark. Файлы назначаются событиям в `concept.events`; смесь строится один раз. Макродвижение получает свой звук, фоновое плавание — тишину. Для следующего выпуска выбирать другую допустимую комбинацию из библиотеки, а не один click на всё.

Можно менять направление раскрытия, характер линзы, последовательность групп, материал и звуковой вариант по смысловой роли. Нельзя рандомизировать порядок причин и следствий, слово/тайминг субтитра, положение лица, safe zone или сигнал успеха вместо ошибки. Случайность выбирается заранее по seed, а не во время рендера.

## Проверка

Все 300 кадров демо и все кадры будущего ролика: реальные размеры текстов, окна, крайние положения переходов. Затем повторный seek и сравнение изображений. Проверить финальный MP4, а не только HTML. Штатный экспорт: `scripts/render-safe.sh`, один worker, ≤4 CPU; качество не снижать.

В исходном демо только SFX и неподвижный тестовый портрет. Он не доказывает трекинг новой записи или синхронизацию речи. В production нужны новая аудиодорожка, реальные времена слов и проверка волос/подбородка. Субтитры по финальному контракту (32,2 px, образец TRACE), буквы не прыгают; подложка только при необходимости, по строке. Публикация и отправка в облако не следуют из запуска навыка.
