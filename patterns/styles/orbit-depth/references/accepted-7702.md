# ORBIT — проверенные приёмы IMG_7702

Исполнение принято по кадрам и сдано локально 15.09.2026. Подробные параметры и доказательства: `videos/reels-17-orbit-7702/PATTERNS.md`, `FINAL-REPORT.md`, `export-state.json`. Это библиотека действий, не обязательный шаблон всех следующих роликов, не cleared publication master.

- **Карусель провайдеров:** один непрерывный GSAP-driver управляет X, крупностью, прозрачностью и активной подписью. Центр больше, уезжающие логотипы меньше; у карточки один владелец transform. Ambient drift — на другом вложенном слое или отключён для самой карусели. Подлинные SVG и их названия не деформировать. Число провайдеров и скорость определяет речь; 15 за 4,35 с — параметр данного ролика, не норма.
- **Переключаемая ветка:** тот же запрос видимо достигает лимита и переходит к другой модели. Связь/стрелка раскрывается после своего узла, не оставляется пустой линией. Один осмысленный запрос связывает состояния.
- **Мост памяти:** капсула договорённостей сохраняется между сессиями; собственная схема сочетается с настоящей записью работы. Факт воспроизводимой работы показывать видео, не имитировать статичным screenshot.
- **Пресс контекста:** сначала реальная работа и заполненный результат, затем один узнаваемый 3D-looking пресс объясняет уменьшение повторов. Важная строка сохраняется; код и логи сравниваются отдельно. Не превращать демонстрационные проценты в личный benchmark или обещание финансовой экономии.
- **Замечание → новый навык:** настоящая последовательность ошибка / Keep–Drop / новое правило сочетается с собственной обратной петлёй. Статичный пример рекомендаций Setup остаётся рекомендацией, не выполненной автоустановкой. Чужой обзор не выдавать за собственную рабочую систему.
- **Портрет и стыки:** лицо в отдельном свободном коридоре, плавный мотивированный переезд; назначенный foreground anchor остаётся на каждой границе. Сохранённый порядок: крупная графика → свободный путь автора → спокойные серые субтитры по настоящему таймингу.

Фоновую среду менять минимум три раза по общему контракту; смена окружения не считается новой причинной механикой. Значимое действие получает релевантный короткий SFX; каждый логотип и тихий параллакс не озвучивать. В этом выпуске 17/17 cue events из основного пакета. Рандомизация только совместимых takes/фаз с сохранённым seed.

## Регрессии и недорогая проверка

- После HTTP Range seek дождаться `seeked`, `readyState >= 2` и обновления кадра (две RAF в проверенном capture-процессе). `currentTime` сам по себе не доказывает, что на снимке новый decoded frame. Контролировать независимым source comparison, а не только браузерным скриншотом.
- 2K: root, html/body и capture viewport согласованы с 1440 × 2560; логический 1080 × 1920 canvas масштабирован равномерно 4/3. Родительский overflow не должен отрезать правую/нижнюю часть и портрет.
- Encoded QA сравнивает обе стороны с одинаковым AREA-resampling. Не ослаблять пороги из-за разных фильтров уменьшения. Сохранять первичный провал и исправленную методику; если картинка не менялась, повторить анализ существующего MP4, не полный рендер.
- После одобрения: один малонагрузочный 2K экспорт, фактический bitrate и post-AAC loudness, all-frame проверка автора/якоря, source checks вставок, визуальное ревью двухсекундных листов и переходов. Target 48M не равен измеренным 18,4 Mbit/s.
- Сдача и очистка: `knowledge/approved-delivery-cleanup.md`. Знания/ассеты остаются, лишние готовые MP4 и одиночные QA-файлы — нет после проверенной доставки в Загрузки.
