## Механика

1. Выбрать 2–3 узнаваемых объекта, которые действительно участвуют в объяснении. Их связи важнее украшений.
2. Разложить их по глубине: центральный чуть ближе, крайние с умеренным поворотом. Подписи не должны закрываться соседями даже в перспективе. Вариант с плотным веером допустим только для объектов без читаемого текста.
3. Сохранить смысловой объект через переход: запрос, контекст, выделенную строку или осмысленный контейнер. Следующая сцена принимает тот же объект. Folder/dock — один вариант исходного демо, не обязательный механизм каждой сцены; не подменять причинное действие несвязанным dissolve.
4. Раскрывать узлы и связи причинно: связь появляется после её целевого узла. Финальный импульс проходит только по существующему пути.
5. Сохранять портрет в отдельном свободном коридоре. Спокойный сдвиг в противоположную часть кадра мотивирован композицией, не случайностью.

## Исполнение

HTML/CSS/GSAP, без React-миграции. Редактировать storyboard и parts, собрать index через assemble.py. Перемещение и уменьшение растровой папки делать x/y/scale, не left/top: последние могут дать пиксельные рывки. Transform-origin задаётся явно. Сложный материал — кэшированный растр с прозрачностью; не генерировать изображение каждый кадр. 2.5D не выдавать за полноценную 3D-сцену.

Фон тёмный, подписи светлые; стекло не должно пропускать чужие буквы так, что они читаются через передний объект. Корпоративные логотипы только настоящие, папка и символы в демо — обобщённые объекты, не логотипы сервисов.

Звуковое семейство orbit: fan / paper / engine / catch / route / impact / drop / pluck / resolve. Большой жест получает звук, фоновый параллакс — нет. Seed и выбор файлов фиксируются до рендера. В будущих роликах менять материал/тембр по назначению, не менять тревожный сигнал на успех ради разнообразия.

## Приёмка

Сначала все кадры в браузерном QA, затем визуально ключевые кадры и окна переходов, потом финальный MP4 и его аудиодорожка. Проверить загрузку CSS-фона отдельно от img. Проверить подписи крайних документов: автоматическая геометрия внешней группы не выявляет внутреннее перекрытие. Сверить safe zone и лицо в конечных и промежуточных позах.

Экспорт через render-safe.sh: один worker, ≤4 CPU, качество high/CRF16. Исходное демо 10 с: SFX-only, тестовый стоп-кадр автора. Для живого экспертного ролика нужны фактическое видео/тайминг речи, трекинг лица и субтитры 32,2 px по финальному контракту с подчеркиванием слова; на тёмном фоне светло-серые, размер не увеличивать автоматически.
