This is a compact editorial interpretation of the project's saved audit, not a newly measured platform experiment. Detailed paths below are relative to `reels-montage-pipeline`.

## Findings that change writing decisions

- Target: at least 50K views, not unique reach. No available audit proves a guaranteed formula or the causal effect of a script or editing style.
- Reference selection starts with topic relevance and observed performance. Compare a high-view Reel with weaker posts from the same creator, adjusting interpretation for age, length, ads and duplicate content. Missing private metrics stay unknown.
- Pronin's useful grammar is an understandable system that changes as the explanation progresses: risk/problem → cause → visible connections → check → conclusion. A familiar form, server, record or real screen is more relevant than generic tech decoration. The user has approved an ONai cut-out head narrator for this series; this overrides the earlier split-screen recommendation for this specific format.
- A reference stack combines subject, opening function, visual grammar and an ONai example. Do not reproduce the competitor's script, distinctive avatar or graphic assets.
- One completed explanation can travel to another viewer. A keyword giveaway alone does not demonstrate meaningful discussion, trust or sharing.
- Instagram, TikTok and Shorts require platform-specific packaging and analysis. There is no demonstrated universal duration, daily-posting bonus or required cut every 1–3 seconds. Use a clean master and judge the viewers' actual response.
- Four reviewer lenses: emotional recognition, accurate hook/payoff, substantive discussion, useful transmission. Choose one primary reaction per Reel. Use independent agents only when independence is actually requested or warranted, not every time a short script is drafted.
