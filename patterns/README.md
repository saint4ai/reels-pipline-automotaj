# Каталог паттернов монтажа

Всё, чем собирались ролики @saint4ai: стили целиком, паттерны отдельных роликов, паттерны движения, переходы, приёмы и разборы
референсов. Агент берёт отсюда **метод и блоки**, а карту монтажа каждый раз придумывает заново под текст
(`knowledge/montage-concepts.md`, «своя карта монтажа»).

Картинки для выбора владельцем — прямо в чат:
- `reference/style-previews/styles.jpg` — стили 1–4 (собраны на студии Remotion этого репозитория);
- `reference/style-previews/more-styles.jpg` — паттерны 5–12 (кадры готовых роликов).

У каждого ролика в `patterns/reels/<ролик>/` лежит `frames.jpg` — шесть кадров из готового MP4.

## Паттерны движения — отдельные блоки

Готовые блоки из ролика 22 (вариант «Фокус») — `studio/src/examples/vibe/blocks/`, у каждого в шапке фраза, под которую он сделан:

| Блок | Что делает |
|---|---|
| `Hook` | стеклянный пузырь-цитата с огромным словом с первого кадра |
| `Rewind` | «Перемотка стройки» + «Рекурсия кадра»: кадр ролика отматывается к сборке и оказывается внутри самого себя |
| `Deck` | «Колода фокусника» + «Осколки собираются»: кейсы вытягиваются из колоды, осколки складываются в картинку |
| `SlotLevel` | «Слот-машина профессий» + «Прокачка»: барабан профессий и шкала уровня |
| `XRay` | «Рентген» + дорожка модулей: сквозь обложку видно содержимое курса |
| `Pour` | переливание: один промпт разливается в сайт, приложение, AI-менеджера, автоматизации |
| `Explode` | «Разбор на детали»: предмет разлетается на составные части с подписями |
| `Gift` | подарок раскрывается, внутри — система |
| `Mirror` | «Непослушное отражение» + «Стоп-кадр с облётом» |
| `Tear` | «Разрыв кадра» на две стороны выбора |
| `Cta` | финальный призыв с кодовым словом |

Из ролика 22 «Живая сборка» (`studio/src/examples/course/live/`): курсор агента с кликами, выделение с ручками, клавиши,
перечёркивание и стирание слова, 3D-песочные часы (`Hourglass.tsx`), чек-лист с зачёркиванием и полосой «сделано»,
дорожка модулей с бегунком, карусель карточек, дашборд со счётом чисел, мок Reels с комментарием, закреплённый чип.

Библиотека `studio/src/kit/`:

| Блок | Что делает |
|---|---|
| `Porthole` | 3D-иллюминатор: камера влетает в окно, нутро становится следующей сценой |
| `Phone` | 3D-телефон с титановым ободком поверх HTML-экрана, лента директа |
| `Spotlight` | прожектор: темнота с круглым просветом и объёмным конусом света |
| `StackSpread` | стопка карточек разлетается по кадру |
| `LiquidCapsule` | капсула из жидкого стекла с водой внутри |
| `Plug` | 3D-штекер с кабелем — «коннектор» буквально |
| `Toggle` + `Cursor` | тогл «вручную → автомат», по которому кликает курсор |
| `BrowserCard` | окно браузера с настоящей записью экрана, камера подводится к нужному месту |
| `GridCanvas` | холст в клетку для прогулки камеры |
| `Sticker` | карточка-наклейка вместо 3D-иконки |
| `pixel` | «воксельное стекло» (проба, владелец не утвердил как стиль) |
| `presentations` | переходы сцен, снятые с референса по кадрам: `portal`, `blurThrough`, `bloom`, `whip`, `shrinkTo`, `lift` |
| `liquid/Glyph` | пролёт камеры сквозь букву (`scripts/glyph-paths.mjs`) |

## Карта путей

Документы писались в основном пайплайне автора, поэтому в них встречаются его пути:

| В документе | Здесь |
|---|---|
| `labs/remotion-route/src/kit/…`, `src/ds/…` | `studio/src/kit/…`, `studio/src/ds/…` |
| `labs/remotion-route/src/reels/<ролик>/…` | `studio/src/examples/<ролик>/…` |
| `labs/remotion-route/scripts/…` | `studio/scripts/…` |
| `public/objects/*.png` | `studio/public/objects/*.webp` |
| `reference/brand-logos/…` | `studio/public/brand/…` |
| `reference/audio/onai-apple-pack` | `studio/public/sfx/` (нарезки) |
| `skills/onai-<стиль>/` | `patterns/styles/<стиль>/` |
| `videos/<ролик>/PATTERNS.md`, `DIRECTION.md` | `patterns/reels/<ролик>/` |
| `knowledge/<файл>` приёмов | `patterns/techniques/<файл>` |

Код роликов в `studio/src/examples/` — образцы: он проходит проверку типов, но записи и скриншоты этих роликов в репозиторий
не входят, поэтому целиком их не рендерить — брать блоки и приёмы в свой ролик.
