# Старт за 10 минут — для тех, кто пришёл из рилса

Этот репозиторий — пайплайн монтажа вертикальных рилсов, на котором собирались ролики
[@saint4ai](https://instagram.com/saint4ai). Монтирует агент у тебя на компьютере: Claude в обычном
чате видео не отрендерит, а здесь всё собирается локально — HTML + GSAP → MP4 через HyperFrames.

Ничего не ставь руками через терминал: отдай ссылку Claude, он поставит сам. Руками — только
регистрация, подписка и ключи доступа.

## 1. Что нужно

- Компьютер: Windows с WSL, macOS или Linux. Чем больше ядер процессора — тем быстрее рендер.
- Подписка Claude (Pro или Max) и приложение Claude для компьютера с вкладкой **Code**
  (или Claude Code в терминале).

## 2. Установка — одним сообщением Claude

Открой вкладку Code, выбери папку для проектов и отправь:

```text
Склонируй https://github.com/saint4ai/reels-pipline-automotaj и подготовь всё для монтажа по SETUP.md:
запусти scripts/bootstrap-portable.sh, поставь то, чего не хватает (Node.js 22+, ffmpeg, Python 3, Chrome),
проверь npx hyperframes@0.8.20 doctor. Почини, что не работает. Когда всё готово — прочитай CLAUDE.md
и docs/agent-contract/WORKFLOW.md и сразу начни опрос: задавай мне вопросы по одному.
```

Дальше агент сам проведёт тебя по шагам: спросит, о чём ролик, есть ли текст и запись, какой формат монтажа,
дашь ли скриншоты и материалы. Пункты 3–5 ниже — для справки, если захочешь управлять вручную.

## 3. Скажи Claude, кто теперь владелец

Правила писались под автора, поэтому в них встречается «Александр». Отправь:

```text
В правилах этого репозитория «Александр» — это владелец проекта. Теперь владелец — я:
вопросы по формату, стилю и приёмке задавай мне.
```

## 4. Сними запись

- Вертикально 9:16, лучше 1080×1920 или 4K; свет на лицо, петличный микрофон.
- Не обрезай и не ускоряй — пайплайн работает с исходником как есть.
- Говори по готовому тексту: на каждую фразу агент подберёт действие в кадре.

## 5. Первый ролик

Модель: в Claude — самая новая Opus с усилием xhigh (минимум high); в Codex — `gpt-5.6-sol` с `model_reasoning_effort = "xhigh"`.

```text
Новый рилс «<название>». Проведи опрос по docs/agent-contract/WORKFLOW.md и дальше работай по этапам.
```

Агент пойдёт по шагам и будет спрашивать по одному вопросу: о чём ролик, есть ли текст и запись, какой формат монтажа
(экспертный с записями экрана, разговорный со вставками или подкаст), дашь ли скриншоты и материалы, есть ли референсы,
как сдать. Текста нет — напишет сам: ресёрч, черновик и три скептика (эксперт-зритель, копирайтер прямого отклика,
редактор удержания), потом покажет финальный текст. Монтаж начнётся только после твоего «да».
Упомянешь сервис — логотип и интерфейс он найдёт в открытом доступе; не найдёт — спросит.

## 6. Референсы: как собирать

1. Найди 2–3 рилса, которые нравятся **монтажом**, а не темой. Сохрани видео.
2. Положи в `reference/inbox/` и отправь:

```text
Разбери референс reference/inbox/<файл> по образцу reference/breakdowns/2026-09-02-ref-0902-claude-limits.md:
структура по времени, раскладка, подложка, шрифты, переходы, ритм. Сохрани в reference/breakdowns/<дата>-<имя>.md.
```

3. При монтаже: «Возьми за основу разбор <файл>, но тексты и тема — мои».

## 7. Проверка кадров и правки

```text
Покажи лист кадров каждые 2 секунды.
```

Правки пиши обычными словами и по номерам кадров: «кадр 7 — субтитры крупнее», «на 12 секунде
логотип раньше». Агент правит сториборд и пересобирает.

## 8. Рендер

```text
Всё ок, рендерь.
```

Готовый ролик — в `videos/<проект>/renders/`. Перед отправкой агент проверит кадры самого MP4.

## Как не сжечь подписку

- Не проси «прочитай весь проект» — у агента есть `scripts/pipe.py`, он спрашивает у проекта
  только нужное (в 25–34 раза меньше текста, замеры в README).
- Один ролик — одна сессия; длинные сессии закрывай и начинай новую от файлов.
- Не проси показывать кадры по одному — только листами.
