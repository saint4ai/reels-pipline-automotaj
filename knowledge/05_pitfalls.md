# Грабли

Реальные, на каждой наступали. Проверять до сборки, а не после.

## Качество картинки

**Тройное перекодирование.** Собирали по шагам: нарезка → пауза → вставки. Каждый файл
перекодировался заново, битрейт упал с 7,7 до 4,7 Мбит/с, картинка посыпалась.
→ Собирать одной командой ffmpeg через `filter_complex`.

**Даунскейл из 4K не спасает, если кодировать быстро.** `-preset fast -crf 18` на вертикали
с движением даёт мыло. → `-preset slow -crf 15 -tune film`.

## Прозрачный слой

**ProRes 4444 и webm не сохраняют альфу.** Отдают `yuv422p12le` и `yuv420p` — слой ложится
чёрным прямоугольником. → Только `--sequence --image-format=png`.

**Имена кадров меняют разрядность.** 75 кадров → `element-00.png`, 924 кадра →
`element-000.png`. ffmpeg с неверным `%0Nd` падает с «Could find no file».
→ Смотреть `ls out/seq | head -1` перед сборкой.

## Раскладка

**Блок по центру садится на лицо.** Лицо крупным планом занимает y 500–1500.
→ Смещать вбок (`right: 74`) или в верхнюю треть (`paddingTop: 13%`).

**Субтитры перекрывают вставку.** При `MarginV 340` субтитры на y ≈ 1520.
Вставка с `bottom: 430` попадает прямо под них.
→ Держать вставки выше `y 1400`.

**Длинный русский текст переполняет плашку.** Кегль, подобранный на глаз, ломает вёрстку.
→ `fitText` из `@remotion/layout-utils`; для длинных фраз — `fitTextOnNLines` с `maxLines: 3`.

## Текст и шрифты

**`fitText.ts` знает только заглавные буквы.** Таблица ширин снята под субтитры капсом.
Для текста в обычном регистре берёт запасное значение 0.96 на символ — завышает ширину
и ужимает кегль до нечитаемого.
→ Для смешанного регистра — `fitText` из `@remotion/layout-utils` (реальный замер).

**Шрифт не загружается кодом.** `loadFont` вызывался только в незарегистрированной композиции.
Всё держалось на том, что Benzin установлен в системе — на другой машине рендер молча
берёт системный шрифт.
→ `src/overlay/fonts.ts` импортируется в `Root.tsx`.

**Кириллица в модных шрифтах отсутствует.** Bebas Neue, Boldonse, Big Shoulders,
Bricolage Grotesque — 0 из 64 глифов. libass подменяет молча, текст выглядит «кривым».
→ Проверять через `fontTools.ttLib` перед использованием.

**drawtext с кириллицей ломает парсинг ffmpeg.** → Писать текст в файл и брать через `textfile=`.

## ffmpeg

**Видео в `media/` без ремукса не играет в браузерных редакторах.** Файлы, скопированные
через `cp`, не имеют `moov` в начале.
→ `ffmpeg -i in.mp4 -c copy -movflags +faststart out.mp4`

**Переменные окружения не раскрываются внутри `filter_complex`.**
Ошибка «Output with label 'vout' does not exist».
→ Подставлять полные пути прямо в строку фильтра.

**Функции шелла с именами системных команд** (`cut`, `build`) молча не срабатывают.
→ Переименовывать или писать инлайн.

**Один кадр в ffmpeg 8** требует `-update 1`, иначе ошибка про паттерн имени.

**Рассинхрон при паузе.** `tpad` удлиняет только видео.
→ Обязательно парой: `tpad=stop_mode=clone:stop_duration=N` + `apad=pad_dur=N`.

## Дрожание и артефакты

**Zoompan даёт тряску на малых шагах.** Масштаб меняется рывками по целым пикселям.
→ Апскейлить источник до 2800px перед `zoompan`, тогда шаг субпиксельный.

## Транскрипт

**Автораспознавание путает термины.** «вайпкодинг», «неронка», «Дерум» вместо «Дилором».
→ Прогонять словарь замен.

**Строки субтитров YouTube перекрываются по времени.** Конец предыдущей залезает на начало
следующей — слова дублируются.
→ Обрезать конец каждой строки по началу следующей.

**Фразы обрываются на полуслове.** Резать по границам смысла, а не по таймеру: найти в
транскрипте, где мысль началась и закончилась.

## Нагрузка на машину

**Локальный Whisper кладёт мак.** `mlx-whisper` на большой модели съедает память, приложения
падают.
→ Брать субтитры YouTube; если нужен свой прогон — `nice` и маленькая модель.

**Рендер кадрами занимает место.** 924 кадра PNG 1080×1920 — около 70 МБ, плюс кэш webpack.
→ Чистить `out/` после сборки; следить за свободным местом до старта.

## HyperFrames: рантайм и параллельные агенты (2 сентября 2026)

**Клип с `data-duration ≤ 0` ломает рантайм с этого момента и до конца.** После такого клипа перестают
обновляться спикер, статичные слои и даже сетка фона, старые субтитры не гасятся. `lint` и `check`
это не ловят; аудит движения сообщает лишь «never reaches visible opacity» для всего, что позже.
Источник в нашем случае: чужая правка `durationSeconds` в storyboard.json (25.3 вместо 51.15), из-за
которой сборщик обрезал группы субтитров по концу композиции.
→ `scripts/assemble.py` отбрасывает группы за пределами композиции и не выпускает клипы короче 0.3 с;
`pipe.py state` блокирует любые `data-duration ≤ 0`; `validate` V15 блокирует речь длиннее композиции.

**Два агента в одной папке проекта.** Сессия Opus перезаписывала `index.html` и `storyboard.json`
параллельно с моей сборкой. Час ушёл на бисекцию из-за чужой правки одного числа.
→ Один проект — один агент. `index.html` несёт `<meta name="hf-assembled">` с хешем сториборда;
`state`, `build` и `render-safe.sh` отказываются работать с файлом, собранным не из текущего сториборда.

**Бисекция HyperFrames-композиции за минуты.** Копия проекта с симлинками на `media/` и `assets/`,
правка одного параметра в storyboard.json, `assemble` → `check --json`, несколько копий параллельно
(по 70 с каждая). Так за 4 раунда исключены раскладка, кастомный JS, медиа, звук, шрифты, SFX.

**HTML-комментарий в рукописном фрагменте** сбивает парсер линтера: первый тег после комментария
считается корнем композиции. Комментарии только в CSS/JS.

**`compositions/` линтится как саб-композиции.** Рукописные фрагменты класть в `parts/`.

**Прерванная составная команда выполняется частично.** Следующий патч, ищущий старые строки, молча
не совпадает. Правки файлов — только с проверкой совпадения (assert) и перечитыванием перед правкой.

**`pkill -f` по шаблону, который есть в собственной командной строке, убивает саму команду.**

**«Сделай как у Codex» по кадрам даёт раскладку, а не облик.** v2 повторила зоны и ритм утверждённого ролика
и всё равно выглядела чужой: другие тени, скругления, гарнитура надзаголовков, способ акцента (цветной текст
вместо маркера), плашка субтитров на всю полосу. Всё это лежало в 150 строках CSS, которые никто не читал.
→ Эталон переносится из его CSS/JS в `frame.md` проекта (токены), и только потом собирается. Снимки — для проверки.

**Div-свип фона ловится layout-чеком** («extends outside a clipping container»), даже при `overflow:hidden` у
родителя. → Декор, выходящий за кадр, рисовать псевдоэлементом `::after`.

**Два CSS-правила на один контейнер субтитров.** Добавленное `#caption-stack{inset:0}` перекрыло `top/left`
старого правила, а `width/height` 840×120 остались — плашка уехала в левый верхний угол, и layout-чек показал
«перекрытие заголовка». → У контейнера субтитров одно правило; при переезде полосы двигать `y` через GSAP.

**Кроп чужих записей экрана.** Опус нарезал 4K-запись настроек в четыре разных кропа; между склейками диалог
«уезжал», стрелка и рамка указывали в пустоту, границы диалога срезаны. Александр: исходники не резать.
→ Запись целиком, `object-fit: contain`, бокс по пропорции; время подгонять скоростью (`setpts`) или тримом.

**Голова в нижней половине.** При окне 1080×960 из 720×1280 голова, занимающая 33 % кадра исходника, становится
633 px и не помещается между полосой субтитров и зоной описания Instagram (493–585 px). → Для формата «спикер на
всю половину» снимать так, чтобы голова занимала ≤ 26 % высоты кадра; иначе подбородок уходит под описание.

**Белый логотип на платине невидим** (Composio). → Белые знаки только на чёрном чипе.

**Переезд полосы субтитров через лицо.** Твин полосы при смене раскладки шёл 0.28 с уже поверх появившегося
спикера. → Стартовать переезд на 0.22 с раньше смены, в провал спикера.
