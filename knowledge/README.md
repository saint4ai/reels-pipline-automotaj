## С чего начать новый ролик

1. Формат и стиль — по `montage-concepts.md`, картинками владельцу.
2. По расшифровке разметить, где какой класс смысла (`03_rules.md`), и написать карту монтажа в `videos/<проект>/DIRECTION.md`.
3. Плотность: 6–9 событий на 30 секунд, новый элемент не чаще раза в 1,2 с, фон меняется на каждом смысловом блоке.
4. Собрать в студии, проверить контейнеры (`qa-fit`), показать листы кадров каждые 2 с, после «да» — рендер и мастеринг.
