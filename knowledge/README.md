## С чего начать новый ролик

1. Открыть [03_rules.md](03_rules.md) — по транскрипту разметить, где какой класс смысла.
2. Проверить плотность: 6–9 событий на 30 секунд, между тяжёлыми 4–5 секунд чистого экрана.
3. Взять готовые приёмы из `projects/remotion_reels/src/overlay/beats.tsx`.
   Пример сборки — `SecurityV2.tsx`, двадцать строк на весь ролик.
4. Отрендерить слой кадрами, собрать одним проходом ffmpeg по [04_pipeline.md](04_pipeline.md).
5. Прочитать кадры глазами: текст не переполняет, ничего не село на лицо, вставки не под субтитрами.

## Что важно знать сразу

- **Прозрачность — только через `--sequence --image-format=png`.** ProRes и webm альфу теряют.
- **Один проход кодирования.** Каждое лишнее перекодирование съедает картинку.
- **Приёмы, трогающие саму картинку** (наезд, тряска, спид-рамп), в прозрачном слое невозможны —
  делать отдельным проходом ffmpeg или переносить видео внутрь Remotion.
- **Числа плотности — гипотеза.** Выведены арифметикой из замеров в `src/rules.ts`,
  отдельно не проверялись. Подтвердить на 3–5 роликах.
