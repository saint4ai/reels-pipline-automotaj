# Три формата рилсов — что спрашивать и как собирать

Перед любым монтажом агент спрашивает Александра одно: **какой формат?** Ответ определяет раскладку, ритм и
источники. Не угадывать. Записать ответ в `DIRECTION.md` первой строкой.

## Разговорный рилс с вставками — как удерживать внимание без экранов

Речь без графики держит 3–4 с, дальше отваливаются. Правило вставок: каждое смысловое существительное или
число получает объект наверху (штамп, чип со знаком, число с pop, рукописная подпись, короткий список
терминалом), объект живёт 1.5–2 с и уходит, следующий появляется на следующем слове-триггере (03_rules §1).
Между вставками спикер меняет положение H ↔ T, а фон меняет радиал. В T-фазах верх занимает кинетический
стек по словам; в H-фазах — карточка с одной мыслью. Три слоя движения: слово субтитра (караоке),
объект наверху, смена положения спикера. Никаких зумов на спикере; динамика только сменой состояний.

## Подкаст-рилс — уникальная система

1. Отрывок выбирается по описи `reference/clips-index.md` (балл ≥ 60) или новой серии `videos/podcast-clips`.
2. Спикер: вертикальный кроп подкаста по говорящему (Александр — центр кадра 4K), окно H. Другие участники
   появляются вставкой сверху как «реплика собеседника»: кадр 16:9 в экран-карточке с адресной строкой имени.
3. Верхняя половина — смысловой канвас: схема мысли (SVG рисуется штрихом), цифры счётчиком, цитата
   собеседника карточкой, футаж из самого подкаста (у него уже есть авторские вставки) в экран-карточке целиком.
4. Заголовок отрывка — первая фраза-хук из описи, Manrope 800, стоит первые 2 с над канвасом, потом уходит.
5. Субтитры на шве 960, караоке; финальные 3 с — плашка «полный выпуск — в шапке» + знаки площадок.
6. Готовый отрывок = отдельный проект `videos/podcast-<slug>` из `new-reel.sh`, спикер `media/speaker.mp4`
   = вертикальный кроп, речь `media/speech.m4a`, транскрипт словами из `transcript.words.json` по диапазону.
