# parts/ — контракт рукописного объекта

Единственный HTML, который пишет агент. Всё остальное собирает `scripts/assemble.py`.
Файлы: `parts/<name>.html` (фрагмент разметки, без `<html>/<body>`), `parts/<name>.css`, `parts/<name>.js`.
Сборщик инлайнит их в `index.html` и отдаёт JS переменные `SB` (весь сториборд), `tl` (единый
`gsap.timeline({paused:true})`), хелперы `show(sel,start,end,axis)`, `pop(sel,at,overshoot)`,
`draw(sel,at,dur,len)`. Эталон: `videos/reels-1-composio/parts/spine.*`.

## Правила, каждое проверено линтером или check 2 сентября

1. **Без HTML-комментариев** в `.html`: парсер линтера принимает первый элемент после комментария за корень
   композиции и требует от него `data-composition-id`. Комментарии — в CSS/JS.
2. **Не класть фрагменты в `compositions/`**: HyperFrames линтит эту папку как саб-композиции. Только `parts/`.
3. **Движение только трансформами** `x`, `y`, `scale`, `rotate`. Твины `left/top` — ошибка
   `gsap_non_transform_motion`. Высоту и ширину менять можно (`height`), это не движение.
4. **Никаких CSS `transform` на элементах, которые анимируются GSAP** (`translateX(-50%)` для центровки
   запрещён): конфликт `gsap_css_transform_conflict`. Центровать через `left/width`.
5. **После каждого затухания — жёсткий `tl.set(sel,{autoAlpha:0},t)`**, иначе
   `gsap_exit_missing_hard_kill` при сике назад.
6. **Не тюнить `display`/`visibility` на элементах с `class="clip"`** — ими владеет фреймворк. Внутри
   `parts/` клипов нет вовсе: медиа объявляются в сториборде (`clips`, `audio.hits`).
7. **Дочерние элементы, выходящие за обрезанный контейнер** (плитки внутри свёрнутой доски):
   `data-layout-allow-overflow` на контейнере детей, иначе `layout container_overflow`.
8. **Все id уникальны** на странице; префиксовать именем объекта (`#spine-board`).
9. **Все времена из `SB`**, литералов в JS нет. Слово события — в сториборде, валидатор сверит его с речью.
10. **Цвета только утверждённые**: лайм `#B6FF00`, оранж `#FC5C02`, чернила `#111214`, серый `#6E6E6E`.
    Смена цвета — `tl.to(sel,{backgroundColor|color|borderColor})`, не классы через `.call()`
    (класс не откатывается при сике).
11. **Шрифты**: Gilroy 900/800/500/400, STIX Two Text Italic 700, Benzin когда появится. Другие имена
    `state` пометит как неутверждённые.
12. **Слои**: фон 0, объект 3, вставки 4, спикер 5, подсветка CTA 6, субтитры 20, переходы 30.
    Объект не заходит в полосу субтитров `y 904–1016` и в окно спикика ниже `y 1060`.
13. **Иконки** — inline SVG с `stroke="currentColor"`, чтобы менять цвет твином; логотипы брендов —
    `<img>` из `assets/brand/` с записью в `ASSET_SOURCES.md`.
14. **Готово** = `python3 scripts/pipe.py build <project>` без BLOCKING и ошибок, лист снимков
    просмотрен, дефекты и решения записаны в `DIRECTION.md`.
15. **После рендера — кадры самого MP4** (правило Александра): лист 4×5 по всему ролику
    (`ffmpeg -vf "fps=1/2.5,scale=300:-1,tile=4x5"`), смотреть глазами: субтитры внутри подложки, объекты
    не накладываются, окна в кадре. Снимки композиции до рендера этого не заменяют.

16. **Закон наложений.** Ни один объект сцены не пересекает другой, полосу субтитров или окно спикера
    (`validate` V26 — BLOCKING). Субтитры не лежат на экранах и футажах. Указатели (рамка-подсветка, стрелка)
    — единственное, что кладётся поверх экрана. Облик элементов — `knowledge/09_design_system.md`.
