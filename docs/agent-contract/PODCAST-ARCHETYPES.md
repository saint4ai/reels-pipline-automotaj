# Архетипы подкаст-рилсов — чтобы ролики не выглядели одинаково

Александр (03.09, 05:00): «радиальные круги везде, формат один и тот же, никакого креатива». Причина — все
ролики шли по одной структуре: кикер-хук → карточки с объектами → карточка-вердикт со штампом → чип. Различались
только типы объектов. Теперь два уровня различий обязательны: **скин** (дизайн-язык, поле `skin` в сториборде,
рисует сборщик) и **архетип** (структура сценария, поле `_archetype`, реализует режиссёр). Одинаковых пар в серии
подряд быть не должно.

## Скины (`skin`)

| skin | Канвас | Карточки | Субтитры | Настроение |
|---|---|---|---|---|
| `platinum` | светлая платина, сетка 96, свип, цветные радиалы | paper с рамкой и жёсткой тенью | плашка .24, серые → белые | эталон, рост, деньги |
| `ink` | тёмный графит, белая сетка, слабый свип, радиалов нет | тёмные с белой рамкой | без плашки, слова серые → белые | безопасность, шпионаж, ночь, код |
| `paper` | тёплая бумага с точечной сеткой 48, без свипа | **без рамок и теней** — типографика прямо на канвасе | плашка чернильная | истории, тетрадь, личное |
| `poster` | сплошной лайм, тёмная сетка | чёрные с белым текстом; акценты чёрным на лайме | плашка чёрная | дерзкие заявления, цифры-удары |
| `mono` | серый монохром, красный `#C61F32` вместо оранжа, серый маркер вместо лайма | светлые | плашка чёрная | страх, риск, «тебя заменят» |

## Архетипы (`_archetype`) — скелеты сценария

**poster — типографический постер.** Карточек нет вообще. 4–7 кинетических сцен, каждая — 1–3 слова огромным
кеглем (роли heavy/accent/number), слова меняются каждые 1.5–2.5 с; штамп-удар на переломе; число role number.
Чип CTA как обычно. Скины poster / ink / mono.

**terminal — единый терминал.** Одна карточка на весь ролик (или две), внутри `listStyle: "terminal"`, строки
появляются по словам речи все 25–50 с — как лог событий; заголовок карточки меняется через `labels`? нет —
делай 2–3 карточки-терминала подряд с разными `termTitle`, каждая 10–20 с. Никаких note/stamp внутри; финал —
последняя строка терминала лаймом (последняя строка списка) + чип. Скин ink.

**notebook — тетрадь.** Рукопись как главный голос: карточки с `headlineStyle: "script"` и 2–4 `note` на карточку,
появляющимися по словам; `clock` или `arrow` как «зарисовка»; никаких терминалов, баров и счётчиков; в финале
рукописный вывод. Скин paper (или platinum для одного из).

**board — доска с цифрами.** Одна большая карточка-доска на 20–40 с (zone h 640), на которой по ходу речи
появляются counter → bars → chart/второй counter (объекты в разное время и в разных местах, y 200 / 380 / 560,
без пересечений), заголовок доски — тезис с числом; хук — kinetic с числом; финал — карточка-вердикт. Скин
platinum / poster / ink / mono / paper.

**dialogue — диалог.** Речь как переписка: 3–5 `bubble` с репликами (спикер и собеседники, `text` — цитаты речи),
пузыри чередуют x (слева 40 / справа 300), карточка «переписки» одна на 15–25 с; между ними 1–2 кинетики со
словом-ударом; штамп-реакция. Скин mono / platinum.

## Правила для всех
- Хук первые 2 с — не одинаковый: где число, где вопрос рукописью, где одно слово во весь канвас, где сразу терминал.
- Финал — не всегда карточка со штампом: постер закрывается словом, терминал — последней строкой, тетрадь — рукописью.
- Один архетип не повторяется у соседних роликов серии; скин тоже.
- Все прежние правила остаются: слово ↔ событие, ≤ 18 символов заголовок, зоны, чип `{40,780,560,60}`, V26–V28.

## Ограничения после сборки серии (3 сентября)

- Карточка `board`: `subline` не задавать — он в потоке под заголовком и накрывает объекты с y ≤ 200. Счётчик (132 px) выше своего бокса: первый объект доски не выше y 168, следующий не ближе 150 px.
- Терминал: последняя строка и так залита лаймом, `highlight` под ней не ставить.
- Счётчик `color: orange` только на тёмных карточках (ink, poster); на платине и бумаге — `lime` (маркер), иначе контраст < 3:1.
